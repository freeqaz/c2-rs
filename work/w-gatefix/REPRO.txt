w-gatefix — THE TWO-DIRECTION REPRODUCTION OF #2907 / #2668, FROZEN
====================================================================
Boards #2940 / #2941. Every run below is `scripts/gate.sh` AS IT WAS AT THE
MERGE BASE `0d0a74d2`, in this lane's worktree, on 2026-08-10. Machine paths
scrubbed to `<repo>`.

The permanent, re-runnable form of this reproduction is `gate.sh --check`'s
arms `A2` / `A3` and their counterfactuals `C1` / `C2` / `C3`, which drive the
same behaviour against throwaway `git init` trees and against `0d0a74d2`'s own
`hatch_red.py` read out of git. What is below is the incident itself, in the
real repository, once.


--------------------------------------------------------------------------
0. THE MECHANISM, ISOLATED — the arm-count probe is the destructive step
--------------------------------------------------------------------------
`hatch_red_run()` reads the declared arm count with `--list` BEFORE its
interlock, and `hatch_red.py`'s module-level `finally: restore()` fires on that
path too. `--list`'s own docstring (line 5) says "runs nothing".

    $ python3 -c "…prepend a doc line to crates/c2-obj/src/lib.rs…"
    dirty before        : crates/c2-obj/src/lib.rs
    $ python3 work/w-hatch/hatch_red.py --list
    --list exit: 0   lines: 14
    dirty after --list  : (clean)     <-- EATEN BY --list

So by the time the interlock two lines below runs, there is nothing left for it
to refuse over. `hatch_red.py`'s OWN `REFUSING to run on a dirty tree` guard is
also never reached, because `--list` returns above it.

Three things to read off it, in order of cost:

  * the edit is gone;
  * the row said **HATCH-STALE**, not **DIRTY-TREE** — the interlock that exists
    for exactly this saw a clean tree, because the probe had cleaned it;
  * `tree 0d0a74d2` carries **no `-dirty` suffix**. `pin_harness` computes that
    marker with `git diff --quiet HEAD` AFTER the hatch-red row, so the gate's
    one signal for "this is not the tree you handed me" is evaluated downstream
    of the thing that made it false.

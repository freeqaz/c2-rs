WHAT THIS ANSWERS

§4 of docs/ARCHITECTURE_PROPOSAL_2026-08-20.md makes the stage oracle step 0
and the go/no-go for the entire back half of the migration: if c2's
intermediate state cannot be observed, porting its register allocator and
scheduler is unguided guessing and the honest answer is to say so and stop.

IT CAN BE OBSERVED. Neutrally, deterministically, canonically, with a
non-empty payload that cross-derives three ways.

AND THE BOUNDARY IS WORTH MORE THAN THE GREEN: the observable is BLIND TO
COLOR. It moves across the scheduler and across lowering on every function and
is byte-identical across the register allocator on every function, with a
128-byte raw window per tuple saying COLOR writes NOTHING in the tuple record.
A ported COLOR cannot be graded against this snapshot. The allocator's output
lives in the operand records the tuple points to, or in its own candidate
records (P_REGALLOC.md §5's cand+0x28 / +0x3c). That is a concrete direction
for the next lane and it REPLACES the plan's "read P_REGALLOC once the
mechanism is green" with a measurement that rules the tuple out.

FOUR PLAN DEFECTS AND ONE ENVIRONMENT DEFECT

1. "The HMODULE LoadLibraryA returns IS the load base" is FALSE UNDER WIBO —
   it returns 0x00000018. The first armed run computed slide=ef500018, every
   site failed the fail-closed opcode check, and NOTHING WAS PATCHED. The
   invariant did its job on its first outing. Slide now = GetProcAddress
   ("_InvokeCompilerPass@12") - 0x10bebffd, cross-derived against
   VirtualQuery's AllocationBase.
2. Per-site __declspec(naked) thunks DO NOT BUILD — GCC does not implement the
   naked attribute on i686, and i686-w64-mingw32-gcc is the only compiler
   ensure_c2host uses. Replaced by ONE top-level __asm__ thunk that recovers
   the site from the return address the `call` already pushed. Smaller, and it
   removes the compile-time cap on site count.
3. FlushInstructionCache is a missing import in wibo and SIGABRTs the process.
   Dropped: x86's icache is coherent, one thread, bytes written before c2
   executes them.
4. This lane's own first neutrality test added a "stronger" third assertion
   and it FAILED with Differs{first_offset:8, a_len:1725, b_len:1721}. Offset
   8 is PointerToSymbolTable and the delta was the embedded /Fo PATH STRING,
   because the leg wrote to a scratch path. c2 was neutral all along. A
   stronger check that silently changes the command is worth less than none.

THE MECHANISM — AND THE BRIEF'S PREMISE DOES NOT SURVIVE CONTACT (#3245, #3246).
The lane was told a guard binding all raise sites of one key is worth far more
than four witnesses, and that if it cannot be done, why not is the finding. The
answer is neither: the mechanism is real but rare, and it is not what makes the
census's population GREEN.

  * It does not apply to this family AT ALL. Each of the four keys has exactly
    ONE raise site — registered as a frame fact in the prereg §1.1, read out of
    the source BEFORE the first probe so it could not be discovered afterwards
    and told as a result. These four were unguarded because nobody wrote a
    witness, not by construction.
  * SIZED OVER THE WHOLE CRATE: of the 18 census fence keys in body/mod.rs,
    15 have k <= 1 (14 at k=1, one at k=0 — F5's key with no fence). Only three
    have k >= 2. F2's entire predicted contribution is sum(k-1) = 5 SITES
    against 30 GREEN observed: a 17% ceiling. callee-unresolved is not an
    exception to F2, it is the MODAL CASE.
  * THE CENSUS'S OWN TABLE ALREADY REFUTES THE 1/k BOUND. MULTI_PRODUCER is k=2
    with BOTH sites RED — rows L6 and L7 — because
    every_bind_gate_fires_on_a_named_input already carries one witness per site
    at leaf_store.rs:3166 and :3174. The suite F2 characterises as "per-KEY" is
    in fact a witness TABLE that already does site-level coverage wherever
    someone bothered. The limit is how many rows were written.
  * F2'S LEADING WORKED EXAMPLE IS DEAD CODE. leaf_store.rs:2456 (row L9) cannot
    be reached by any input: both walks of bind_run_ops are over the same
    immutable ops slice, the second strictly after the first, and the first
    already establishes that every 3k-th op is a Load — so the second's
    `if !matches!(b, IlOp::Load(_))` can never be true. Verified by reading, and
    LABELLED AS A READING. Sixteen lines above it the file records its own prior
    instance of the same class (w-mrslot §5.1, #1218).
  * SO THE CONSTRUCTION THAT GENERALIZES NEEDS NOTHING INSIDE c2-il. F2 proposed
    "a #[cfg(test)]-visible discriminant per raise site, OR a witness table
    required to cover each site". The second half alone suffices: a table with
    one row per RAISE SITE, keyed on the input that reaches it, buildable from
    outside the crate wherever the site is reachable at all — which it must be,
    or the site is dead. This lane lands that table. #3245 exists so the next
    lane does not reach for the discriminant.

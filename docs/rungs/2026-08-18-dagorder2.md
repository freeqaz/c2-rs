## 6. Found and not taken

1. **The A-series head/tail split** — `h g f | b a c d e` at n=8, with the head
   growing `0,0,0,1,1,2,2,3` over n=1..8. A composition of the schedule, the
   accumulation weights and (at n ≥ 6) register pressure; this grid does not
   separate them. The highest-value open item, and the cheapest next cell family
   is an n-series with the *live set* held at 2 while n grows.
2. **`cnd_s2` / `cnd_s2r`** — `a-b` and `b-a` give the *same* assignment, and
   both **invert** the `+` cells. The operator moves the assignment and the
   written operand order does not. `wb-dagorder`'s own found-and-not-taken item
   3 (*"`+`-reassociation is a grid fact; the code that produces it is
   unread"*) is the same gap reached from the allocator side, and closing it
   would close both.
3. **`0x10b2d630` does two jobs** — it narrows the allowed set (#3049) *and*
   accumulates the priority. `wb-live` characterized only the first. Reading the
   weights is F5's cost model and needs an obj cell nobody has built.
4. **A THIRD field-table correction is likely and was not chased.** Two were
   found by using two fields (`+0x18`, `+0x44`); `wb-live`'s table was
   enumerated in one pass and is **phase-flat** by construction. The table
   should carry a phase column, which is a doc change this lane's seam allows
   but whose evidence it does not have.
5. **`W-REGALLOC_FINDINGS.md` §1 still says *"There is no `sched.c`, and no
   instrument scheduler."*** That is **#1823**, refuted by `wb-dagorder`
   (#3067) on 2026-08-13. The sentence is live on master in a whitebox findings

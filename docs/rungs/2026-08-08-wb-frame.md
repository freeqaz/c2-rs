### P1 — the candidate predicate (stated cold)

> c2 opens a stack frame for a function iff **any** of:
> (a) it makes a call that is not a pure tail call (non-leaf);
> (b) it has stack-resident locals (address-taken, aggregate, or spilled);
> (c) it must save any callee-saved register (GPR `r14..r31`, FPR `f14..f31`, CR);
> (d) it uses EH, `alloca`, varargs homing, or a stack probe.
> Otherwise it is frameless and the whole body runs in volatiles.

Registered sub-prediction: **(a) alone is sufficient and is the dominant clause**
— a function with one call, no locals and no saved registers still gets the
96-byte frame, because the LR spill slot lives inside the callee's own frame.

### P2 — the size arithmetic

I predict the disassembly **confirms, and does not extend**, the already
black-box-established rule of `docs/CODEGEN_FRAMED_CALLS.md` §1.2:

    localsBase = align16(16 + 8·max(nOutSlots, 8))
    F          = align16( max(16 + 8·max(nOutSlots,8), localsBase + localsBytes)
                          + 8·nSaved + 8 )

i.e. the white-box contribution of this lane is expected to be the **predicate**,
not the size. Registered direction: *pessimistic about novelty* — if the
disassembly hands over a size term the §1.2 sweep never saw (it swept
`nSaved ≤ 17` only), that is a miss in the pessimistic direction and I say so.

### P3 — why `?supershuffle` is 96

I predict 96 = `align16(16 + 64 + 0 + 8)` — Class A, `nOutSlots ≤ 8`, no stack
locals, `nSaved = 0`. Frame opened by clause (a): it has six callees.

### P4 — a challenge to board #1477's own wording

`CODEGEN_FRAMED_CALLS.md` §2.2 is emitted *before* the `stwu`, not instead of it.

> **Registered prediction (optimistic direction, i.e. I expect to be able to

## What it admits, and what it refuses

**Admits** — obj-graded, black-box, re-derivable from the committed grid source:

> **A frame is open iff the body contains a non-tail call.** Stack locals,
> callee-saved registers, FPR use and local size are **not** inputs: a leaf uses
> the space below `r1` (measured to −260) and can save nine GPRs through
> `__savegprlr_23` with no `stwu` at all.

and, as navigation with addresses, the *shape* of c2's decision: one bit of a
per-function flag word from a single linear scan (`0x10bff507`, set only at
`0x10bff5f6`), gated at `0x10bfed12`, sized `base + 8·nSaved + 8` at
`0x10bfed35`, and aligned to 16 **once, after** those additions (`0x10c0b722`) —
which is `docs/CODEGEN_FRAMED_CALLS.md` §1.2 with `[fn+0x68]` naming the base.

**Refuses / retracts:**

* **Board #1477's diagnosis** of `?supershuffle` — the port emits the same
  `9421ffa0`, one word later. Retracted, board row **#1570**.
* **This lane's own predicate as read off the disassembly** (*frame iff any
  call*) — three tail-call cells refuted it. Retracted, not narrowed; the
  obvious rescue ("a tail `b` just isn't kind `0x0f`") is recorded as a
  hypothesis with no evidence and no DISCLOSURE row.
* **No `adoption` DISCLOSURE row is proposed.** Everything a code lane needs is
  already black-box, which is the outcome `DISCLOSURE.md` step 5 asks for. One
  `route:` row (**W-FRAME-1**) is pre-drafted; the narrowed callee-saved window
  behind `DAT_10c2e980` is **held, not proposed** — no cell separates it.
* Grid cell **C7** is `assumption unmet` (a 64-bit core lowers `long long`
  divide to a native `divd`, 0 relocations, so the cell contains no call) and is
  excluded from scoring rather than counted either way.
* The **EH** and **POGO** disjuncts of the reading were declared unseparated
  *before* the run and remain unchecked navigation.

## Found and not taken

Ranked by what the next lane would get:

1. **`?supershuffle` is an INLINER item, not a frame item** (#1573, findings §7).
   14 of the 26 words are the inlined `?shuffle2`; the rest is one
   interprocedural clobber set. **Board #1477 should be re-pointed and the frame
   half of task `w-frame` retired.** This is the single highest-value output of
   the lane and it is a *deletion* of planned work.
2. **The interprocedural register footprint.** c2 keeps a pointer in the
   volatile `r3` across four `bl`s to in-TU callees that provably never write
   `r3`. `10b2778e` (`emit-order`, *"topological sort, callee before caller"*)
   is the plausible mechanism and is **unmeasured**. A reproducer needs callees
   c2 declines to inline — probes 2 and 3 both failed because c2 inlined them,
   and that negative is recorded so nobody re-runs the small-callee version.
3. **The sixth prologue shape** (#1572): frameless + `__savegprlr_N`.
   `docs/CODEGEN_FRAMED_CALLS.md` §2's five classes all have frames; a port that
   trusts that enumeration will mis-shape a register-hungry leaf.
4. **`.pdata`'s `PrologLen` as a free second read of the frame decision**
   (#1572) — one byte per function, already in every reference obj, never used
   by any instrument in this repo.
5. **`[fn+0x68]`, the base frame size, is unread.** It is where the `nSaved ≥ 18`
   spill term that refutes §1.2 in 39 of 480 cells must enter. Not chased.
6. **Instruction kind `0x0f` is unidentified.** Naming it is the cheapest way to
   turn the retracted R0 into either a repaired reading or a second refutation.

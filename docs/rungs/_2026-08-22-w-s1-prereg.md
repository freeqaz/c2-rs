## 1. What is being built, and the honest scope split

`select_function` returns `Selected`, whose `Plain(Vec<u8>)` and `Tail(Vec<u8>)`
variants carry an **opaque byte vector**. Board **#3365** measures those two
variants at `29,312 + 5,310 = 34,622` of `35,894` byte-exact emitted functions =
**96.5%** of everything the port gets right. Surveyed on this tree: **18
producers** reach `Selected::Plain` and **4** reach `Selected::Tail`; **16 of
the 18** build their bytes by direct calls into `codegen::encode`'s 89
hand-written `encode_*` functions with no intermediate representation at all
(only `ptr_walk_loop` and `ptr_walk_chain_loop` go through `block_ir`).

S1's ask is that those bytes be produced by **one general lowering driven from a
per-op value carrying c2's opcode number**, with `Selected::Plain`/`Tail`
deleted from the live path and re-added only as `#[cfg(test)]` cross-checks.

**S1 is priced 2–4 weeks raw / 10–20 weeks calibrated. This is one session.**
The scope is therefore split in advance, and the split is registered so that
"landed less than the row" is scored as what it is rather than discovered at
report:

| part | content | this session |
|---|---|---|
| **S1a** | The **per-op value** — `MachineOp`, carrying **c2's own opcode number** (`docs/whitebox/ref/ENCODE_OPCODES.txt`, read R2) — and **one general composition function** `encode_op(MachineOp) -> u32` implementing `P_ENCODE.md` §5's form rules, with every `encode_*` in `codegen::encode` re-expressed through it. This is the general layer; it is on the live path by construction, because every byte of every `Plain` and `Tail` body is produced by an `encode_*`. | **ATTEMPTED — the primary deliverable** |
| **S1b** | The `Selected` collapse: `Plain`/`Tail`/`MemcpyTail` replaced on the live path by one variant carrying the op stream plus a terminator; the old byte-carrying variants re-added `#[cfg(test)]` as cross-checks. | **ATTEMPTED if S1a lands green** |
| **S1c** | Converting all 18 `Plain` producers to build a `Vec<MachineOp>` natively instead of a `Vec<u8>`. | **NOT attempted. Priced at report.** |

**If only S1a lands, the rung says so in those words and prices S1b/S1c.** A
smaller honest re-expression that holds its delta beats a large diff with a
hand-waved one; that is the brief's instruction and it is registered here so it
cannot be reinterpreted after the fact.

### 1.1 The decision surface (`GOAL_DECISION` § AMENDED, `rungs/README.md`)

The general layer's arbitrary choices ship as **named, enumerable parameters
whose DEFAULT reproduces c2 byte-exactly**, not as baked constants. Registered
in advance, the parameters this lane intends to expose:

* the **base-word table** (per-opcode `u32`), as data adopted from
  `ENCODE_OPCODES.txt` with a `DISCLOSURE.md` row, not as 89 literals hidden
  inside 89 functions;
* the **form** each opcode dispatches to, and each form's **field placement**
  (which operand supplies `RT`/`RA`/`RB`, and each field's width and shift).

Grading is **at the default and nowhere else**. Every non-default configuration
is an instrument state and licenses no emit.

### 1.2 Read-before-probe

Nothing here is fitted. The base words, the form numbers and the arm addresses
are **READ** (`docs/whitebox/ref/P_ENCODE.md`, `WB_ENCODE_FINDINGS.md`, read
R2, 79/79 arms, both tables). This lane fits nothing and runs no probe grid; if
it finds itself wanting to fit a field placement, that is a signal to stop and
read `P_ENCODE.md` §5 instead. **`P_ENCODE.md` §9's own bound is respected**:
the spec starts at a *finished machine tuple*, and the tuple stream (R5) is
UNREAD — so this lane's general layer starts at the port's own operands and
never claims to reproduce c2's tuple construction.

## 2. The three graded-by criteria, registered with their thresholds

### 2.1 Criterion A — required-zero byte delta on the LIVE dispatcher (#3346)

**Threshold: exactly 0 lines of difference. Any non-zero delta = FAILED.**

There are **two** live dispatchers, not one, and this prereg records that
correction to the row's singular phrasing before measuring:

* `crates/c2-core/src/comdat.rs::body_of` — the `/Gy` COMDAT path, 20 `Selected`
  arms;
* `crates/c2-core/src/lib.rs::PortC2::build` — the packed `.text` path, whose
  `Selected` match is **not** a superset of the COMDAT one (it refuses
  `CtorForwardCall`, `FpStoreDiamond` and `MemcpyTail` outright).

Both must show zero delta. Measured as a **line-for-line identity diff of the
per-lane gate counts** (board #290's pattern, #3345's evidence form):

1. `scripts/gate.sh --jobs 4` at base and at tip; the printed per-lane count
   table diffed with `diff`. **Registered expectation: 0 lines.**
2. `C2RS_REQUIRE_TOOLCHAIN=1 cargo test --workspace --release --no-fail-fast`,
   recording **test count AND target count** (a dropped target count means an
   earlier target failed — board #3341: environment is asserted by
   `census_gate` **duration ≥ 60 s**, never by "0 SKIP lines", which is
   vacuous).
3. The 878-TU workload scan: `match` / `mismatch` / `vocab-gap` /
   `codegen-gap`, and every pre-existing `gap-metric` key, unmoved.

**`mismatch` is an alarm outranking all work.** If any run reads `mismatch > 0`,
this lane stops and reports it, whatever else is in flight.

### 2.2 Criterion B — the pre-registered COST criterion (#3336)

#3336's finding is that a required-zero **byte** delta is silent about
everything that is not a byte, and a criterion that cannot fail **abstains
rather than passes**. So this lane names an axis on which it can fail with every
byte identical.

**The axis is port throughput**, chosen because S1a puts a new indirection —
a table lookup plus a field composition — on the single hottest path in
`PortC2::build`: every instruction word the port emits. If a general layer is
going to cost anything, it costs here, and it is measurable.

**Protocol — `ir0`'s, reused verbatim** (`docs/rungs/2026-08-20-ir0.md` §F-5):

* Arms: `base` (the branch's merge-base binary), `tip` (the re-expressed
  binary), and **`nulldup`, a byte-identical `cp` of `base` verified with
  `cmp`** — an effect of exactly zero measured through the entire pipeline.
* **8 rounds**, arm order rotated every round so no arm keeps a slot.
* Population: the fixtures the port `Match`es (the exact set `perf`'s geomean is
  computed over). Its size is recorded at measurement time and published beside
  every figure.
* **Estimator: per fixture and arm, the MINIMUM port median over the 8 rounds.**
  External load can only add time, so on a shared box the minimum estimates
  uncontended latency. Pairing is per fixture, not per round.
* The reference (`wibo`) column never enters the comparison.

**Registered thresholds, before the measurement:**

* **FLOOR:** the null arm's reading is this protocol's noise floor. **No
  conclusion smaller than the null arm is a conclusion** — if `|tip − base|` is
  within the null arm's 95% CI, the registered verdict is **"below the noise
  floor"**, NOT "no cost". ir0 measured that floor at about **±0.4%**; this lane
  re-derives it rather than assuming it, and publishes the null arm's own
  sign-split (an effect of zero must split the sign about half).
* **PASS:** `tip` costs **< +5%** port time per obj against `base`.
* **REPORTED, not failing:** `+5%` to `+15%` — landed with the number stated in
  the rung header and in the board row.
* **DECLINE (see §4):** `> +15%`.

This criterion **can fail**, and that is the point of registering it.

### 2.3 Criterion C — the `after0` opcode-agreement RATIO (instrument, never a gate)

**This is a measurement. It gates nothing, licenses no emit, and never enters
`scripts/gate.sh`.** It is the number a general lowerer's price actually needs.

The quantity: for each distinct `MachineOp` the port's general layer can build,
evaluate the general composition **at every operand zero** (`after0`) and
compare to c2's own `base_word[op]` read from `ENCODE_OPCODES.txt`. Publish
**N of M agreeing**, and — the load-bearing half — **the shape of M − N**: every
residual named, with why it differs.

**Registered expectation, before measuring:** `w-read-r2` (board **#3379**) did
this against the *incumbent* `encode.rs` and got **82/89 = 92.1%**, with **0**
disagreements in a primary opcode or an `XO`, and all 7 residuals being a field
the port bakes that c2's arm supplies (`BO=20` ×2, `BO=16`, the split `SPR`,
`SH`/`MB`/`ME` ×3).

* **Expected population: 89 encoders**, ±5 for encoders this lane merges or
  splits. The denominator is published in the same sentence as the ratio
  (standing rule 4, #3356).
* **Expected ratio: ≥ 82/89.** The general layer composes from the base word
  outward, so it should *raise* agreement or leave it flat — it cannot honestly
  lower it. **A ratio BELOW 82/89 is a finding against this lane's own
  construction** and is reported as such, not smoothed.
* **A ratio of 89/89 is ALSO a finding against the instrument**, and is
  registered here as such in advance: the 7 residuals are real properties of
  where c2 places a field versus where the port bakes one, and an instrument
  that makes them vanish has most likely become a tautology (it is comparing the
  table to itself). If the ratio reads 89/89 the lane must show, per residual,
  that the port's own emitted bytes changed — which criterion A forbids — or
  else declare the instrument circular and publish it as such.

### 2.4 The bijection, promoted as a RATIO and never as an equality (the AMENDMENT)

`w-ildecode`'s `the_final_tuple_order_reproduces_the_text_words` **asserts
equality** over a fenced population of **three functions, nine words** — all
leaf, frameless, call-free, branch-free, memory-free, constant-free, zero
`.text` relocations, one block, `int`, already `Port=Match`, at `/Ox /GS- /c`.
Every one of those properties is shared across the three and **none was
varied**.

**Pointed at the corpus unchanged it goes red on the first framed function**,
because the final expansion switch rewrites the prologue pseudo-op in situ into
many words (`WB_REGALLOC_FINDINGS.md` §4 item 2, `0x2f4`/`0x2f0` →
`0x10bff95c`). **That red would be an instrument defect, not a property of c2.**

Registered: if this lane touches the bijection at all, it reports it as
**"bijection on N of M, and here is the shape of M − N"**, with framed functions
expected in `M − N` **by construction and named in advance**. It is never
promoted as a corpus-wide equality assertion. If time does not permit touching
it, the rung says it was not touched rather than implying it was.

## 3. The base re-measurement, and the STOP CONDITION

**Filed snapshots are not trusted** (see §0 — two of them already disagree). The
first thing this lane runs, before any edit, is the base triple on **its own
tree at `9b9530791`**: `match`, `mismatch`, `fnbyte-exact`, plus the full gate

> ### THE STOP CONDITION — watched for, reported LOUDLY, never patched
>
> **If criterion A's required-zero delta HOLDS but the workload `fnbyte-exact`
> count MOVES AT ALL, the program's pricing basis is VOID and the program should
> stop** (`ROADMAP_SLICING_2026-08-21.md` §5). The reasoning: a pure
> re-expression that changes no obj byte cannot change how many *functions* are
> byte-exact — unless the port's byte-exactness is a **fit** to the shapes'
> populations rather than a model of c2, which is exactly the §4 assumption
> Phase 0 exists to test.
>
> **Registered response, so it cannot be reinterpreted under pressure:** this
> lane does **not** patch, tune, or explain away such a move. It reports it as
> the primary finding, in those words, with the per-symbol movement (standing
> rule 3: never subtracted totals — `w-empty`'s first attempt read `+0/−14`
> where the truth was `+1,373/−0`).

## 4. What would make this lane DECLINE

Registered in advance, because a priced decline is a good outcome and a
retrofitted one is not:

1. **Any non-zero byte delta that this lane cannot close.** Never ship a byte
   delta that is not zero. If the general layer cannot reproduce a word, the
   lane reverts to the incumbent for that word and reports the residual, or
   declines the whole re-expression — it does not adjust the fixture.
2. **Cost > +15%** on criterion B's protocol, measured against the null arm.
   A general layer is not worth a sixth of the port's throughput when the byte
   delta is zero by definition; the honest report is "built, and it costs too
   much to land" with the number.
3. **The opcode-agreement ratio reads below 82/89** and the shortfall is a real
   composition the general layer gets wrong — that is a defect in the layer, not
   a finding about c2.
4. **A shared predicate cannot be widened without narrowing a peer's.** If
   `Selected`, `selected_tag`'s strings, or any `FnByte` variant would have to
   *narrow* to serve this lane, the lane declines that edit and says why.
   `selected_tag`'s `"plain"` / `"tail"` / `"memcpy-tail"` strings are a
   **published interface** — `c2rs gap` prints them and
   `docs/FUNCTION_BYTE_MATCH.md` quotes them — and must survive S1b unchanged.
5. **A peer-lane collision.** `crates/c2-core/src/coff/label.rs` and the
   label-seed machinery belong to `w-seedgap`; the blind-reach /
   `fnbyte-blind-*` machinery belongs to `w-s0`. This lane touches neither. If
   the work turns out to require one, it stops and reports the collision.

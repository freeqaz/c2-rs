## 0. What this lane was asked and what it found

WB-D §9.1 and WB-H §9 item 3 both end on the same sentence: **the pattern set —
instruction selection — is the only "no" left** between a hand-transcribed
function shape and a derived class lowering. WB-D's concrete unread examples
were a `x < 10u` returning 1-or-2 that lowers to a four-word branchless
`subc`/`subfe` carry idiom, record-form versus plain forms, and `cmpwi`/`cmplwi`
selection from the IL type byte (#1788).

All three are the same finding, and the finding reorganises the question:

> **c2 has one opcode field, one opcode space, and sixteen tables.** `instr[1]`
> holds a PPC machine opcode when it is `≤ 0x298` and a machine-independent IR
> operator when it is `> 0x298`; **selection is overwriting that field downward,
> in place**, on a list nothing reorders (WB-D §4). The knowledge is in
> image-resident arrays, not in code, and the *type* is the array's own index —
> which is exactly why one adoption covers every type at once and a
> transcription covers one function.

| what | VA | shape |
|---|---|---|
| mnemonic / operand-format / property flags | **`0x10b1b260`** | 665 × 12 bytes, `_first`…`_last` |
| the 32-bit PPC encoding skeleton | **`0x10c3a578`** | × 4, same index |
| a per-opcode property byte (`0x20` = writes `XER[CA]`) | **`0x10c3afd8`** | × 1, same index |
| the sixteen operator × type opcode tables | installer **`0x10c04cb9`** | 16 × 26 ints |
| the 46-arm per-operator dispatch | **`0x10c0f882`** | jump table on `instr[1]` |
| the compare selector (#1788's site) | **`0x10c0eb17`** | type nibble → fit test → table |
| **the relational-as-a-VALUE driver** | **`0x10c1b517`** | **a costed race** |

and the flagship, which is the one place selection is genuinely an algorithm:

```
a = FUN_10c1ac5c(t, 0);   // the CARRY idiom, cost only
b = FUN_10c1af2d(t, 0);   // the CNTLZW idiom, cost only
if (b <= a) FUN_10c1af2d(t, 1); else FUN_10c1ac5c(t, 1);   // EMIT — TIES TO B
```

`cost` **is the word count**, `500` means infeasible, and a `500` from both is
read upstream by `FUN_10c1b315` @ `0x10c1b315` as *"do not if-convert at all"* —
so the same routine that produces WB-D's four-word carry idiom also decides
when there is a branch instead.

## 1. The grade

12 cells, frozen in `3624bb93` before the first `cl.exe` of the grid, compiled
with real `cl.exe` 16.00.11886.00 under wibo at `/nologo /c /GR /O1 /Oi /EHsc /Gy`.

**Primary (mnemonic sequence, or a stated class): 10 of 12.
Secondary (exact words including every register): 6 of 10 predicted.**

Four cells came out **instruction-word for instruction-word** from a reading
with no obj in the loop. `wbs_s3` is the one to read:

| predicted from `FUN_10c1ac5c` | emitted by c2 |
|---|---|
| `subfic r11,r3,7` `0x21630007` | `0x21630007` |
| `subfe r11,r11,r11` `0x7d6b5910` | `0x7d6b5910` |
| `rlwinm r11,r11,0,28,28` `0x556b0738` | `0x556b0738` |
| `addi r3,r11,4` `0x386b0004` | `0x386b0004` |

The mask is `delta = 12 − 4`, the `addi` is `base = 4`, there is no `li` because
the left operand is the register, and there are four words because
`cost = 2 + mask + base`.

`wbs_s4` was frozen as a **4–4 tie predicted to go to B** — and B won, word for
word. That single cell is this project's only black-box evidence that the
tie-break exists, and no obj could have produced it without the two cost
functions being computed independently first.

## 2. The two misses, and the retraction

**`wbs_b3` is a retraction.** `(int)(x < 0)` was predicted as strategy B's
three-word `cntlzw ; cntlzw ; rlwinm 27,31,31`; c2 emitted **one** word,
`srwi 3,3,31`. Strategy B's reading is not wrong — the sibling cell `wbs_s6`,
the same comparison with the result pair `{1,2}`, *did* take the double-`cntlzw`
form. What is wrong is the claim that B handles `x < 0` as a **bool**: a `{0,1}`
result pair gives type nibble `5`, which the driver routes to `FUN_10c194b8` @
`0x10c194b8`, 890 bytes, **located and not read**. The class predicate
therefore carries an explicit exclusion today, and the next lane's first job is
that routine.

**`wbs_s6` is a miss on a conjunct.** Mechanism right (two `cntlzw`, one
`rlwinm 27,31,31`, no carry), word count wrong (6, predicted 4–5). A prediction
with a false conjunct is a miss.

Three of the four *word-level* misses are one error repeated: this lane
predicted a fresh `r10` where the previous value's live range had already ended
and `r11` was free again. **WB-D §3.4 gives the emitted answer in all three.**
Selection → order → registers held on 12 more cells.

## 3. What the calibration cost, disclosed

`grids/wb-select/calib.cpp` (6 cells, no shared relation and no shared
constant) was compiled first and is unscored. PREREG P6.1 said it would be read
with `--no-disasm`, i.e. sizes only; **`gt_dump.py --no-disasm` still prints the
raw words**, so this lane saw them. The §3.2 template had already been derived
from `FUN_10c1ac5c` and written down before anything was compiled, but the
honest statement is that the carry-idiom cells of §7 are *corroborated*, not
blind. What calibration could not have given — and what the grid still tests —
is the cost function, the normalisation table, the A-vs-B race, the tie rule
and the `500 ⇒ branch` rule. None of those is visible in any obj.

Calibration also earned its keep twice: the `if` spelling of a `?:` is
**byte-identical** (so no cell was spent on it), and cell `wbk_4` showed a
`li -1 ; subc ; subfze` shape that `FUN_10c1ac5c` does not contain — which is
the entire reason rival `R-LC2` was frozen as a live possibility instead of
dismissed. `R-LC1` then beat it on the graded cells, and `wbk_4`'s shape is
recorded as unread ground (§9.5) rather than explained away.

## 4. The judgment

**Yes** — the port can lower an arbitrary straight-line integer body from a
derived pattern set, for a stated class, at an estimated **≈ 640 lines** of
Rust. The class is `expr_straightline_int`: one basic block, integer scalar
operators, relationals as values, loads and stores of locals and parameters, no
calls, and result values that are not `{0,1}`.

**Predicted reach on the first scan: `0`.** WB-D P5.4 and WB-H §9.1 are
untouched — 48 of the frontier's 59 functions die at the port's IL reader
before any emitter question is reachable. A lane that expects a conversion from
this will report a failure. What changes is the price of every future emitter
class, and by more than the loop lane changed it: WB-H shipped one *shape*,
this lane shipped the *index* that made a shape necessary.

```sh

# the readings — flat export only, never the Ghidra project (method doc §4)
grep -n 'FUNC 10c0f882\|FUNC 10c1ac5c\|FUNC 10c1af2d\|FUNC 10c1b517' \
     ~/ghidra-projects/export/c2/decomp_all.c

# the tables (scratch scripts, work/wb-select/, not deliverables)

# the grid
```

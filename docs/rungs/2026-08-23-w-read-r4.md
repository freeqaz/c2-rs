## The result

**The ten refuted keys now HAVE an explanation.** The allocator's tie key is
`cand+0x44`, and `+0x44` **is written** — sole origination site `0x10b55fac` in
`FUN_10b55eae`, a tuple-visit ordinal. So the tie tier is a **sort on a
lowered-program-position quantity**, and `ref/P_REGALLOC.md` §4 consequence 3's
hash-bucket walk is the **third** tier, not the second. Every one of the ten
keys is a source-level property of a *variable*, and a variable is not a
candidate: a symbol with *k* live-range versions mints *k* candidates, so a
one-candidate-per-variable key is wrong **in kind**. Board **#3411**, **#3413**.

**And the 52,416-configuration null was structurally guaranteed.** That search
ranged over *priority functions*; the tie tier is not one. It should stop being
cited as evidence about priority functions.

The deliverable the row asked for — the mint/merge as an ordered algorithm — is
`ref/P_GLOBREGS.md` §1, in four steps with addresses. Item **F1**'s promotion
policy is closed at `0x10b550e5` and contains **no threshold and no mode flag**
(#3414).

## The probe, and the half of it that graded nothing

Control **C2**, `scripts/globregs_c2.py`, preregistered §6 and committed before
any obj was compiled; four failure modes named in advance; both `/O1` and
`/Ox`; degrades to `SKIP: toolchain absent`.

* Positive control **fired in both modes** — without it every green would have
  been discarded rather than published.
* **262 resolved formal→register assignments over 62 grid objs** (70 ladder + 192 permutation), 70 objs compiled in all. The ladder is
  monotone `a_i → r(31-i)` at N=2..8; the **24-permutation grid refutes a
  last-use key on 48 cells**; the two modes agree everywhere, which is itself a
  datum (#3241's `/O1`↔`/Ox` reversal does not reach this shape).
* **G-block, the separator, is UNGRADED — not green and not a refutation.**
  It was built to tell `cand+0x44` apart from plain arena order and came back
  UNCHANGED. The caveat committed with the cell *in the script, before it ran*
  is why: moving a formal's later use into another block changes its live
  range, hence `cand+0x0c`, the **primary** key — so the comparator decided the
  pair without ever reaching the tier the cell was probing. A cell that does
  not reach its tier grades nothing. #3414.

**The binding limit, registered in advance** (prereg §7 item 1, Trap A): the
observable is a many-to-one image of the claim. On straight-line bodies the
`+0x44` ordinal and plain arena order coincide, and **262 assignments do not separate
them**. The *existence and identity* of the tie key is `[R]` verified at the
bytes twice-sourced; *what the ordinal means in program terms* is `[R]` only.
`ref/P_GLOBREGS.md` §6 names the shape of the cell that would settle it.

## 5. THE CONFIDENT CORE, stated separately from the rule

**A rule right on 95 % of cells emits wrong bytes on 5 %** (board #232, 241
commits on master). So the core is stated separately, and it is stated even
though **nothing is shipped** — because the next lane will want it and the
temptation is to ship `R-MEMFIT` whole.

**The core**, on which the measured exactness is **1.000 with no residue**:

```text
   BOTH operand hint bytes are present in the IL, and BOTH are in {01,04,08}
   AND the size operand is a compile-time constant, and is not 0
   AND the optimization word is the workload's favor-SIZE setting  (T = 5)
   AND the destination is a formal or a file-scope object          (never a local)
   ->  n = size / min(hint_d, hint_s);   inline iff n <= 5, else CALL
```

**Exactness on the graded population: 724 of 724 cells, 0 residue.** Every
clause is a *narrowing*, and each is there because dropping it has a measured
counterexample in this rung:

| clause dropped | what breaks | cells |
|---|---|---:|
| hints in `{01,04,08}` | the upper clamp — `10` and `20` occur and divide by 8 | 5 (§4.2) |
| `min` of both | a destination-keyed divisor | 18 (§4.3) |
| constant, non-zero size | the call arm and the empty arm | GRID-M's `var` and `n0` rows |
| favor-SIZE | `T = 10`, at 54 of `GRID-W`'s cells | 54 |
| destination not a local | E-DEADDST, which the port's IL model cannot see | 44 (§3.1) |

**The last clause is the one that makes the core untestable by the port
today**: destination liveness is not a fact `c2-il` carries, so a port
predicate cannot express *"is not a dead local"* and must refuse the whole
local-destination shape. That refusal is free — it is what the port does now.

Per **#2020** — the body ranking and the emitted ranking of a family can

**The pair is 3,848 emitted — 2.95 % of the blocked emitted column (130,560),

**The recommendation is `memset`, and it is NOT the same rung as `memcpy`.**
Two reasons, both from this lane:

1. `memset`'s single pointer operand means **one** hint, so §4.3's correction —

2. The emitted witnesses concentrate: 3,749 over 497 TUs is 7.5 per TU, so the

predicate to a fail-closed path.

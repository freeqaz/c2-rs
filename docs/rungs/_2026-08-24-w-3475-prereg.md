## 2.1 The exact edit (registered before it is written)

One arm in `crates/c2-il/src/func/body/mcall.rs`, mirroring
`parse_expr_classed`'s `0x27` arm token for token:

```rust
Some(&0x27) if v == Vocab::CallArg && off_add_admitted() => { … }
```

* gated on `Vocab::CallArg` only — `IntrinsicRecv` has **no emitter**
  (`Vocab`'s own doc: *"there is no emitter for this position and no
  correspondence to hold it to"*), so widening it would be inventing a
  correspondence;
* gated on the same decision point `off_add_admitted()`, so `C2RS_OFF_ADD=off`
  restores the pre-`w-c1` parser **and** the pre-`w-3475` measure together —
  the two must not be settable apart, or the correspondence has a
  configuration in which it is false;
* TYPE resolved by `shapes::designator::is_ptr_any`, the same predicate the
  emitter's arm uses;
* value model: `st.ptr = true`; pop two, push `ValueClass::Ptr4`; on an
  unfollowable stack, `cstack_ok = false`. It does **not** set
  `ptr_arith_exact` — `27` is the *byte*-offset add, `02` is the scaled one,
  which is why they are different opcodes;
* on a non-pointer TYPE it refuses with `FailKind::Value` **at the `0x27`
  byte**, so the construct is still named `off-add` and the granted-hypothesis
  path (`eat_one_blocker_value`'s `Blocker::OffAdd` arm, which takes any TYPE)
  is unchanged. Cursor restored, `*p` untouched on every refusal — the `2C`
  arm's `probe` discipline.

**Fence.** `crates/c2-il/src/func/body/expr.rs` is `w-c7`'s and **will not be
touched**. `off_add_admitted()` is `pub(crate)` and is *called*, not edited.
`crates/c2-core/src/codegen/calls.rs` is `w-permute`'s and will not be
touched. If the fix turns out to require either, I STOP AND REPORT the exact
edit and its call sites.

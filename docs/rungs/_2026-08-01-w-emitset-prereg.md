# w-emitset — pre-registration

Written and committed **before any measurement of the registered quantities**.
Base `74d0744` (verified: the worktree was created 609 commits behind on a stale
base and was reset onto master before anything else — the failure mode four
lanes hit this week, caught by `git log -1` as the brief requires).

Lane premise: `docs/ROADMAP.md` §9.16.3 — the port has **no emit-set model**, so
only **25 of 871** graded TUs can ever be byte-exact regardless of codegen
quality. This lane builds a *predictor* of c2's emit set and grades it. **No
model ships into `PortC2::build`.** A wrong model does not produce refusals, it
produces missing or extra COMDATs, which is a mismatch, and a mismatch outranks
everything.

## Declared bias

**Borrowed and structural.** I read `LABEL_COUNTER.md` §6.5 before estimating,
and it carries a result that, if it generalizes, decides the lane's hardest
question by itself:

> **The callee is emitted anyway.** `cl 16.00.11886.00` emits a fully-inlined
> `static` (and `inline`, and member) function as its own `.text`/`.pdata`
> COMDAT regardless […] **An un-emitted function costs 0** — an *unreferenced*
> `static` (or `inline`) function is dropped.

So the working hypothesis **H** is: **the emit predicate is REFERENCE-driven,
not inline-driven.** If H holds at workload scale, the `/O1` inline-decline
schedule that §8.1 calls "the least-derivable model in the program" and §6.15.3
calls "generated by no formula" **does not enter the emit set at all**, and the
brief's central worry is misplaced. H is a *fixture-scale* result being carried
to 2.46 M bodies; it is exactly the kind of borrowed prior §9.16.7 scored as a
MISS, and it is registered as falsifiable below (E6).

Second declared bias: **pessimistic on the payoff number (E4)**. §9.9.3 recorded
17,706 emitted symbols (9.89 %) that no census row claimed. A TU containing even
one of those cannot have its emitted set reproduced from `.ex` segments at all.

**The arithmetic E10 registers, stated so it cannot be walked back.** The median
TU carries ~1,650 bodies. At 99.9 % per-body accuracy, `0.999^1650 ≈ 19 %` of
TUs. At 99 %, `≈ 0`. **Per-body accuracy is nearly worthless as a headline** and
the only number that decides anything is E4.

## Controls — each could go red

* **C-base** — the never-emit predictor's per-body (92.77 %) and per-TU accuracy
  printed beside every model. A model that does not beat both is reported as
  worse than nothing.
* **C-mutate** (per #145, a validator that cannot see its own defect is worse
  than none) — corrupt exactly one reference emitted name per TU and require the
  reachable-TU count to fall. A count-only comparison passes this; the
  comparison must be over **sets** (§9.9.3's own falsification design).
* **C-arity** (per #144, *totality residue 0 is not a control*) — report the
  **symmetric-difference size** distribution, not just the count of TUs with
  residue 0. Residue counts entities; arity counts their contents.
* **C-heldout** — fit and grade splits are disjoint **by TU**. Any threshold,
  constant or clause fitted on the fit split only.
* **C-leak** — a body with no bound `emit_name` is labelled `not-emitted` **by
  binding failure**, not by c2's decision. Any accuracy figure that silently
  banks those is fake; they are reported as a separate cell.

* That a predictor good on held-out bodies is safe to ship. The fail-closed

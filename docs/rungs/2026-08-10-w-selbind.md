## 0. THE COMMISSION, AND THE THREE SENTENCES THAT REPLACE IT

> The brief: *"Build the selective binding contract, and convert
> `src/system/math/vec.cpp` (match 23 → 24). … `vec.cpp` is the right first
> target … both constructors are present in `.gl`, its two functions are already
> `fnbyte-exact` 2/2, and the gate refuses solely because it insists on the 438
> bodies c2 discards. Nothing about its bytes is missing."*

The contract is built, it is total, and **it refuses everything** — including
`vec.cpp`, which it does not even reach.

> ### **1. A `.gl` RECORD SET IS A STRICT SUPERSET OF c2's EMIT SET, and a selective binding over it emits a function c2 DISCARDED.** Clause 3 — *"refuse whenever a body c2 EMITTED is unaccounted"* — was shipped inside this lane and graded: **`Port=Mismatch` on 5 generated sweep cases and 30 `mode_cross` cells, 35 wrong objs.** `inline int u; inline int v{u}; int f` puts **2** framed records over **3** `.ex` segments with **0** unclaimed runs of either kind, and c2's 833-byte obj holds `?f@@YAHH@Z` **alone**. The commission's obligation is only **half** the obligation. **Board #2820.**

> ### **2. SO THE CONTRACT IS TWO CLAUSES AND ONLY ONE HAS A WITNESS.** UNDER-emit (an obj **missing** a function) is closed, by clause 3, and the `extern "C"` half of it closes the project's own three-lane-old measured wrong emit (#1721). OVER-emit (an obj carrying an **extra** function) is clause 4, and **nothing in the input discharges it**: `.ex` carries no per-body emit marker (#2787) and nothing in `.gl` separates a record c2 kept from one it discarded. Clause 4 is exactly where **factor A** would attach. **Board #2821, #2822.**

> ### **3. AND THE COMMISSION'S PREMISE IS FALSE UNDER THE SHIPPING READER.** `vec.cpp`'s gate walk binds **0** records — it stops at `gl-stop-26-introduced` on record 9 of the 36 its framing can see — so a selective binding binds **neither** emitted constructor and the 438 discarded bodies are four rows downstream of the actual refusal. *Spelled* is not *named*: `gl_body_start_coverage` reads 373 of 811 and its own doc calls `present` a deliberate over-count. **Board #2823, #2827.**

The lane's deliverable is that contract, the instrument that measures its
denominator on every future scan, and the join in §4 — which moves the
acceptance path's published bound from **29** to **34**, and to **414** if board

## 2. THE CONTRACT, AS THE CODE ENFORCES IT

`Bindings::selective`, called by `IlBundle::functions()`. `per_record` is the
case where the selection is everything, so every TU the port already emits is
unaffected **by construction** and not by measurement.

> A selective binding binds a *subset* of the `.ex` segments and emits exactly
> that subset. It is sound only if the subset **IS** c2's emit set, which is
> **two** obligations and not one, because the port can be wrong in two
> directions and each has its own witness:
>
> | direction | the wrong obj | what discharges it |
> |---|---|---|
> | **UNDER-emit** — a segment c2 emitted that the port leaves unbound | an obj **missing** a function | clause 3, and it works |
> | **OVER-emit** — a segment c2 discarded that the port binds and emits | an obj carrying an **extra** function | clause 4, and **nothing in the input discharges it** |
>
> 1. **every record's framed body-start offset must BE an `.ex` split point.** A
>    record whose offset is not a body start is a name attached to something
>    that is not a body — `docs/GAPS.md` §6's defect class, which the oracle
>    cannot grade.
> 2. **no two records may name the same segment**, and the records must run
>    forward through the segment list.
> 3. **UNDER-EMIT — every `.gl` symbol run that could be a COFF symbol name must
>    be claimed by a bound record.** Both halves are required: a **mangled**
>    unclaimed run is a name the reference obj may define, and an **inline-fit**
>    unclaimed run is the `extern "C"` shape #1721 records `looks_mangled`
>    cannot see.
> 4. **OVER-EMIT — the bound record set must BE the emit set, and NO WITNESS FOR
>    THAT EXISTS ON TODAY'S INPUT.** A `.gl` record is c1xx saying *this
>    translation unit has a body for this symbol*; it is **not** c2 saying *I
>    emitted it*. So this clause refuses unconditionally, and the selective path
>    is a stated refusal rather than an acceptance the port has no warrant for.

**Clause 3 has no callee escape and the incumbent 1:1 gate does.** `functions()`
accounts an unclaimed `.gl` symbol against the resolved callees of the functions
it built. Under the 1:1 binding every locally-defined name is a *bound segment*,
so the inline fence sees it; under a selective binding an unbound segment's name
is exactly what a callee account would hide — the port would emit a `bl` against
a symbol it declares undefined-external while c2's obj **defines** it.

**Why "not the widening `w-vec` §8 ruled out" is not a safety argument.** That
rung's sentence is *"binding fewer names than segments is the one change that
lets a wrong obj out of the gate on 851 TUs."* This binds fewer **segments** than
names, which is the opposite quantifier — and the wrong obj came out anyway, by a
door that sentence does not describe (§5). Written into the code beside the
clause, because the reasoning that made clause 4 look unnecessary was exactly
this shape.

### 2.1 The clause-3 shape was measured BEFORE it was written

A pre-parse *"zero unclaimed mangled runs"* clause would refuse TUs the incumbent
path already binds — `mmio.cpp` (11 records / 11 segments) has **1** and
`wordwrap.cpp` (3 / 3) has **2**. `EncryptXTEA.cpp`, a match, has **0** unclaimed
mangled runs and **4** unclaimed non-mangled ones, which is why the clause is
over the mangled **and inline-fit** populations and not over every run. The
clause is asked **only when the binding is genuinely selective**, so none of
those three ever reaches it.

### 2.2 The open edge of clause 3, named rather than left to be found

A run that is neither mangled nor inline-fit is not counted, and one such shape
is a real symbol: a long undecorated `extern "C"` name (`_vswprintf_s_l`, 14
bytes, string table — the W-EXTDATA population). It is not counted because the
same population holds the source path, `__C1_11886`, `size_t` and bare type
names, and no reader in this crate separates them (#1721: *"a filter separating
those from a real symbol is a rung of its own"*). **Clause 4 makes the edge
unreachable today.** A lane that gives clause 4 a witness must close it in the
same commit, and the code says so at the clause.

The PREREG named the VOID condition as *"the unclaimed set turning out to be

wrong**, for a reason the VOID clause could not express: I wrote an antecedent
about the clause I had built and none about the clause I had not. The 488

`vec.cpp`** — the walk binds 0 records, so clause 3 is never asked, and the

**The transferable form**: an antecedent that only makes the registered clause
*true* is not the antecedent the claim needs. The claim was *"the contract
refuses, and here is which clause"*, so the antecedent had to be *"and no
earlier clause fires"* — one line, checkable in the same measurement, and it
would have flagged the `[0, 811, …]` reading on the first scan instead of in §1.2.

   reading is not "C7 should have been priced lower" — it is that **a row whose
   only defence is a gate row must be scored against a gate run, and this lane's
   first gate run is the one that scored it.**
2. **The fixture scan would not have caught it, at either mode.** §6.3's `/Ox`
   half read 0 changed on the *broken* tree. The shape needs 66 `.ex` segments

3. **The reasoning that made clause 4 look unnecessary is written into the code

   `Bindings::selective`'s doc as a warning rather than as a justification.

### 9.3 C10 — the unnamed-refusal budget, spent at a pre-armed place and once beyond it

Pre-armed (c) fired: `Bindings::names()` is consumed as *"one name per segment,

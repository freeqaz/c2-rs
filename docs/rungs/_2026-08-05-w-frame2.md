## 3. #602 — the LAYOUT, and the axis is SYMBOL-GROUP CROSSINGS

### 3.1 The grid, built so it could contain its own counterexample

The prereg's §3 requirement, because three lanes have now built a grid that
could not: `w-sym`'s 7,589 cells contain the `[0,2]` counterexample family
**six times** — one fit cell, one holdout cell and the four `x_split` externals.
That is not a population, and "1,866 of 1,867" reads as a near-exact rule with a
nuisance residual when it is a rule with a *systematic* half.

So this grid **sweeps the symbol mask exhaustively** over each word rather than
sampling it: every non-trivial two-valued mask of every canonical producer word
at lengths 5 and 6, fillers held fixed, plus a one-symbol reduction control, a
second-base-register tier, and four holdout tiers.

```
cells generated : 62365        fit 33798   holdout 28489   external 78
cells with an UNCLAIMED instruction: 0
per tier : A 1200  G 2500  K 1200  M 42724  N 9672  O 970  Q 3000  R 900  S 121  X 78
```

**The falsification check passed by construction and by count**: the family
appears **255 times in FIT alone**, and for every cell that says `slot(1) = 2`
there is a sibling with the same word and a different mask that says
`slot(1) = 1`.

Three shapes the previous grid had **no** instance of also appeared:

| observed layout | `min(i, u_lead)` says | fit cells |
|---|---|---:|
| `[0, 2]` | `[0, 1]` | 255 |
| `[1]` | `[0]` | **144** |
| `[1, 2]` | `[0, 1]` | 41 |
| `[1, 1]` | `[0, 1]` | 37 |

### 3.2 The mask sweep names the axis, on one word, to the cell

Fix the word `{f0; f1; f2; f3; f4; m = k}` — five unproduced stores and one
producer — and read the layout at every mask the grid carries. It is `[0]` or `[1]`, and
the split is **exact** on the number of maximal same-symbol segments of the
emitted store order: **≤ 3 segments → slot 0, ≥ 4 → slot 1**, **63 masks to
nil** across both partitions.

Generalised and measured per producer, the quantity is

> **`nsw`** — the number of symbol-group **transitions** in the final store
> order, up to **and including** the store that first consumes this producer.

`(i, nsw, u_lead)` **determines** the slot for **98.44 %** of the 61,495 FIT
producers — 27 keys, no free parameter, and the figure is the fraction of
producers landing in a key with a single observed answer. Four cut variants of
`nsw` were scored on the same quantity and this one is the best: `< fc`
97.48 %, the whole run 94.04 %, the leading unproduced run alone 92.26 % and
92.51 %. No four-feature set over thirteen
candidate features gets the ambiguity below ~1.1 %, so a per-producer rule over
these features **cannot** be exact on the whole population — which is why what
ships is a gate and not a closed form.

### 3.3 `nsw` is exactly what separates `x_2sym` from `x_split`

The cells board #602 is named after, at the same statements, the same store
order, the same producer order and the same registers:

```
 syms 000011   P0 · stw m0 · P1 · stw m1 · stw m2 · stw m3 · stw e4 · stw e5     nsw(P1) = 1
 syms 001011   P0 · stw m0 · stw m1 · P1 · stw e2 · stw m3 · stw e4 · stw e5     nsw(P1) = 3
```

One store moved to the other symbol takes the second producer's crossing count
from 1 to 3, and the producer lands one slot later. `order.rs`'s new test
**recomputes those three crossings from the rule** and asserts the refusal,
rather than transcribing the answer.

### 3.4 What ships, gated — and it is EXACT out of sample

> capped at 2. **Provided every producer has `nsw ≤ 2`**, the producer at
> emission index `i` is emitted immediately before store slot `min(i, u)`.

| fit | 30,271 | **30,271** | 0 |
| **holdout** — 3 symbols, mixed kinds, ≥ 3 producers, length 7, all held out **wholesale by shape** | 24,891 | **24,891** | **0** |

**The gate is a sufficient condition for the clause's exactness, verified out of

`nsw ≤ 2`, on 28,489 cells the fitter never opened. Per holdout tier, and every

## 7. The shipped property, split rather than blurred

**The guard is additive-refusal by construction.** `leaf_store` reads
`order::producers_lead(&stmts) == Some(false)` and refuses on that and nothing
else. A wrong answer from `layout_slots` can therefore *add* a refusal (losing
coverage, emitting nothing) and can never turn a refusal into an accept. That is
the same sentence `w-sym`'s `order.rs` change carries, and it is why nineteen
refuted rules have produced zero wrong objs. It is **inert today by
construction**: `hoisted_lit` requires every store of the run to take the same
literal, so the run has no unproduced store, `u` is 0, and the model puts the
producer at slot 0 — which is where the hoist already puts it.

**`schedule()`'s own widening is additive-ACCEPT, and I am not going to call it
anything else.** It returned `None` for every multi-symbol run and now returns
`Some`. What makes that defensible is (a) it has **no caller under `crates/`**,
so it moves no byte today, and (b) a future caller inherits `MAX_SYMBOL_CROSSINGS`,
which is exactly the gate measured exact on 24,891 out-of-sample cells. Its
doc comment says this in those words, so the next lane reads the hazard at the
function rather than in a rung.

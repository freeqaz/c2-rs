## 2. What the section emitter ACTUALLY does — R-SEC, at the workload's profile

Cells in `work/w-section/cells/`, compiled by **real `c2.dll` under wibo** at
`/nologo /c /GR /O1 /Oi /EHsc`, dumped with `scripts/gt_dump.py`. **Measured
before the prereg was frozen and labelled as measurement there**, so §2 scores
nothing — registering an already-taken measurement as a prediction is scoring a
coin after it landed.

| rule | what | witnesses |
|---|---|---|
| **R1** | **one `.rdata` COMDAT per DISTINCT literal**, deduped by bytes across the whole TU | `s4` (`"aa"` in `f1` and `f2` → **one** section), `rev` (`"bb"` in `f1` and `f3` → one) |
| **R2** | placed **immediately after the `.text` of the FIRST function that references it** | `s3`, `s7`, `rev`: `.text .rdata .text .rdata .text` |
| **R3** | within one function, **source-argument / first-reference order** — the **reverse** of the `lis` order | `s1`, `s2`, `n3`, `n4` at n = 1…4: `aa` · `aa bb` · `aa bb cc` · `aa bb cc dd` |
| **R4** | raw size = literal bytes **+ NUL, no padding** | `len1`…`len65`: raw = n+1 exactly |
| **R5** | `Characteristics` = `0x40001040 \| (nibble << 20)` — MEM_READ \| CNT_INITIALIZED_DATA \| **LNK_COMDAT** — nibble **3** (align 4) below raw 64, **4** (align 8) at and above **the boundary is pinned to the byte**: raw **63** → nibble 3, raw **64** → nibble 4 (`len62`/`len63`), with `len34`/`len35` inside the lower band. The same size promotion board **#1703** measured for a COMDAT `.data`, here on a `t = 1` narrow char array |
| **R6** | `Selection` **2** (SELECT_ANY); aux `CheckSum` = the **real** CRC; `Number` 0 | `s1` aux `(3, 0, 0x35F3FBF1, 0, 2)` |
| **R7** | symbols: the `.rdata` **section** symbol (STATIC, 1 aux) then the `??_C@_0…` symbol, **EXTERNAL**, `Type` 0, `Value` 0 | every cell |
| **R8** | relocations are **REFHI+PAIR / REFLO+PAIR against the `??_C@` symbol itself**, addend 0 — **no anchor, no pool difference** | `s2`'s four records name **both** literals |

**R2 is the finding.** It is the interleave `crates/c2-core/src/coff/writer.rs`

the string COMDAT is **not** *"a section in the middle of the section table"*; it
is at the one place the port's writer already puts a `.rdata`.

## 3. What shipped

One arm in `func::sy::ex_exit_label`, `crates/c2-il/src/func/sy.rs`:

```rust
found.or_else(|| if seg.contains(&EX_ASSIGN) { None } else { uncorroborated })
```

where `uncorroborated` is the **last** anchored
`54 02 [4F 01 <line>]* 29 <tok>` site, corroborated or not.

**The gate is the absence of the byte in the whole segment, not "the
corroboration failed."** The corroboration is a *disambiguator*: every rival
reading it exists to reject — a `29` inside another opcode's operand, an inner
`return`'s label — needs a `3A` somewhere to be misread. Where there is none
there is nothing to disambiguate. A segment that **has** a `3A` and still cannot
corroborate is exactly the ambiguous case and it keeps failing closed, which is
what `wmain_no_return_neg`'s sibling test now pins.

The binding does not rest on this arm alone and that is the whole reason it is
safe. A token it returns must still

* name a block whose header token is **unique in the file**,
* bind in **strictly increasing** order against the previous segment, and
* pass **`formals_agree`** — every `.ex` formal token declared by that block.

`formals_agree` is the independent content channel, and it is the check that
caught the positional binding being wrong 343,315 times while every gate in this
repo stayed green.

### 3.1 What it does NOT do

It does not teach the port to emit a function with no return value. **Every body
this arm newly binds still refuses**, at `body-0x54` or `call-ref-0x54` — the
statement layer reaching `54 02` with nothing to carry there. This rung admits a
**binding**, not an emission, and the census delta is exactly **0**.

## 2. What was under test, and why it is not a ninth restatement

The eight keys in `codegen/alloc.rs`'s graveyard are each a function of **one
producer's own fields** (`uses`, `kind`, `first`), or of **one expression's own
shape** (`KEY ILX`: does the value carry an offset-add chain), or a **field
edit** on the emitted instruction (`RULE BIND`). w-ilx §6.1 says the fact that
separates the killing pair is *"a relation between **two** expressions, so the
carrier is not a per-producer enum at all"* — and then declines to state a rule
over it. H-2X is that rule:

```text
  H-2X   the address producer takes POOL_TOP (r11)  iff  cu <= ru + 1 + d
           d = 1 when the ROOT SYMBOL TOKEN of the value expression differs from
               the root token of the designator ITS OWN stores are written
               through
         DOMAIN: two producers, one an address that is a PREFIX of (or equal to)
         every address it is stored into, the other one `li`.
```

`d` is readable in the `.ex`: every designator base is `B9 <tok> <TYPE>`
(w-ilx §6 / board #909), so `d` is `tok(value) != tok(store)`. It is **not** a
fact about the address, which is equal in every cell where `d = 1`.

### 2.1 It fits everything on record, and the prereg says that is worth nothing

62 of 62 in-domain GRID M cells, 20 of 20 in-domain GRID V cells, 22 of 22
`SELF-2B` cells across five lanes' committed tables — **97 distinct cells**, the
three populations overlapping in 7 — scored by hand in `PREREG.md` §2.2 before
this lane compiled anything. And §2.2 says, in the same paragraph:

> *"NOT ONE of them is evidence. The magnitude of `d`'s bonus (+1) is read
> straight off those `SELF-2B` cells; it is exactly what makes `cu <= ru+2` fit
> them."*

`RULE W2` was 388 of 388 and `RULE BIND` 33 of 33, and #912's standing lesson is
that a rule which fits its own cells has no standing. **The lane fitted nothing
and graded once.** What was new was the **predicate**, and the prereg identified
the two cells in the world that test it.

### 2.2 The 2×2 nobody had completed

## 5. The IL fact, DECODED — the thing that survives whatever the rule does

`w-mixed` §4.4 established that the difference *is* in the `.ex`, by byte-diffing
two streams. That says the fact is readable; it does not say what the fact is.
`work/w-self2b/roots.py` decodes it, through w-ilx's `exdec.py`, which is ported
from `crates/c2-il`'s own readers. It reads the IL and nothing else — no obj, no
disassembly, no register.

```text
  cell   class          STORE designator root         VALUE expr root          obj
  Z1     SELF-1B        tok 0x0e0a formal [48, 0, 0]  tok 0x0e0a formal [48,0] const
  Z2     LOAD           tok 0x130a BIND   [0]         tok 0x130a BIND   []     const
  Z3     SELF-2B agree  tok 0x130a BIND   [0]         tok 0x0e0a formal [48,0] prod
  Z4     SELF-2B differ tok 0x130a BIND   [0]         tok 0x0e0a formal [48]   prod
  Z5     MIRROR         tok 0x0e0a formal [48, 0, 0]  tok 0x130a BIND   []     const
  Z6     TWOBIND        tok 0x140a BIND   [0]         tok 0x130a BIND   []     prod
```

Read off the table:

* the two spellings differ in the `.ex` in exactly the **root token** of one
  `B9 <tok> <TYPE>` and in the offset-add literal **list** that follows it;
* `prod` appears exactly where the **store designator's** root token is a temp
  **bind head** (`26 <tok>`) **and** differs from the value expression's root
  token;
* `Z5` has differing roots and is `const` — the relation is **not symmetric**;
* `Z2` has a bind store root and is `const` — *"the stores go through a bind"* is
  **not enough**, which is what killed `H-MIX`.

**So the fact is a relation between two `B9` roots plus one bit about one of
them.** `alloc::Producer` carries `uses`, `kind` and `first`; `c2-il`'s
`eat_offset_adds` returns the **sum** of the literal list rather than the list
(#908). Neither can hold it. The minimal honest carrier is w-ilx §6.1's, now with
a measurement behind it: **per producer, the `(root token, is-a-bind, literal
list)` of BOTH the value and the lvalue.**

### 5.1 The SCHEDULE and the ALLOCATION are decided by different bits — #1222 sharpened

`w-mixed` established from a committed disassembly that `w-spell`'s `2base`
spelling is a **schedule** fact and not a register fact (board #1222). That is
right, and GRID Z shows it is not the whole story, because it has a family where
the schedule flips and the registers do not
(`work/w-self2b/sched.out`, read off the committed `dis.txt` by displacement
alone):

```text
  fam  class                store     roots    schedule      alloc
  Z1   SELF-1B              a formal  same     INTERLEAVED   const     c p c c c p
  Z5   MIRROR               a formal  DIFFER   INTERLEAVED   const     c p c c c p
  Z2   LOAD                 a BIND    same     BLOCKED       const     c c c c p p
  Z3   SELF-2B agree        a BIND    DIFFER   BLOCKED       prod      c c c c p p
  Z4   SELF-2B differ       a BIND    DIFFER   BLOCKED       prod      c c c c p p
  Z6   TWOBIND              a BIND    DIFFER   BLOCKED       prod      c c c c p p
```

The **schedule** bit is *"is the store designator's root a bind"* — which is
`docs/SYMBOL.md`'s pin (two stores through different base symbols are never
reordered past each other) plus #1128 (a bind **is** a second base symbol). The
**allocation** bit is that **and** *"do the two roots differ"*.

**`Z2` is the cell that separates them.** It has the bind schedule and takes the
same registers as the two interleaving families. So a lane that reads the
schedule and infers the allocation is wrong on `Z2`, and one that reads the
allocation and infers the schedule is wrong on `Z2` the other way. Board
**#1235**.

### 7.0 This lane broke #1135 ON ITSELF, and the repair is the row

**Reported because it is the useful part.** `work/w-self2b/scrub.py`'s first

is worth its own sentence: **the standing "assert NUL-free" check, spelled with

is a fact about writers and not about timing. It fires:

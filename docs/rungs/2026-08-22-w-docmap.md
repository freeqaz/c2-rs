## 1. What it built, and the one thing it refused to build

Three documents and one script. **Zero files moved, zero renamed, zero dated
records edited, zero generated files hand-edited.**

| artifact | what it is |
|---|---|
| `docs/README.md` (rewritten) | a purpose-first router. An "if you are asking… go to" table at the top, then every one of the **70** top-level documents and all four subdirectories in a themed table, each row carrying **what question the doc answers** and a **freshness class** |
| `docs/DOC_CONVENTIONS.md` (new) | the conventions the tree already follows, recovered by reading it |
| `docs/whitebox/README.md` (new) | an index for a directory that had 64 documents, four TSV exports, 13 obj grids and no index above `ref/` |
| `scripts/doc_cite_audit.sh` (new) | the cross-doc citation detector named at #3367, #3368 and #3370 |

**One stale claim went out with the rewrite rather than being patched.** The
2026-08-19 `docs/README.md` opened by declaring that *"scope of each doc is the
**MVP function class** — a single straight-line integer-arithmetic leaf
function"*. That has not been true of this directory for weeks — `CFG_SHAPE`,
`EH_RECORDS`, `OBJ_DATA_BSS_SHAPE`, `CODEGEN_FRAMED_CALLS` and a dozen others
characterize classes far outside it — and a peer lane flagged it during this
wave. It is gone because the whole opening was replaced; nothing patched it in
place. **The freshness-class table is what stands in its stead**, and it is the
better answer: a per-document class cannot go stale the way one global scope
sentence did.

**What it refused to build: topical subdirectories.** That is the shape
`../decomp-synth/docs` uses and the one the brief warned about, so it was
priced rather than assumed — §3.

## 2. The instrument was built first, deliberately

The brief listed the citation auditor as a *stretch*. It was built first
instead, because without it this lane has no way to say whether it damaged
anything: `scripts/board_audit.sh` answers a different question and cannot see
cross-doc breakage at all, which is the whole content of #3367/#3368/#3370.

`--self-test` is a **positive control**, not a smoke test. It plants one
unresolvable target and one out-of-range line in a throwaway tree and asserts
the engine reports exactly those two, exits non-zero, and stays silent on the
`work/` `../` `~` and URL classes.

**It earned its keep on its first run**, which FAILED:

```
<ctl>/CONTROL: MISSING TARGET      sibling/X.md
<ctl>/CONTROL: MISSING TARGET      notes/HOME.md
CONTROL FAILED: expected exactly 2 findings
CONTROL FAILED: a suppressed class was reported as a finding
```

(The paths in that transcript are written `<ctl>/CONTROL` rather than verbatim
for the reason `DOC_CONVENTIONS.md` §3 gives: the auditor does not skip fenced
code blocks, so pasting its own output into a rung doc adds two findings to the
next run. That is item 6 in §5.)

The token regex started at `[A-Za-z0-9_]`, so `../sibling/X.md` matched from
`sibling/` — the suppression on `^\.\./` could never fire. A detector that had
only ever been run on the real tree would have shipped that, and it would have
reported sibling-repo references as broken citations forever.

Three more false-positive classes were found the same way, each closed with a
stated design point rather than a filter:

| symptom | fix |
|---|---|
| `ref/README.md`, written inside `docs/whitebox/ref/` and meaning its own sibling, read as missing | resolve relative paths against **every ancestor** of the citing directory, not just the repo root |
| `mod.rs:1856` reported out of range against a 16-line file — `mod.rs` exists **13 times** in this tree | a **bare name the tree holds more than once is never range-checked**. Existence still counts; the guess does not. This one class had fabricated **40** findings in a single run |
| `axes1/RESULTS.md` — lane scratch that was never in the tree | a relative path whose first segment names no directory anywhere cannot be judged; counted under a named class instead of guessed at |
| `_FINDINGS.md` (from prose about `WB_*_FINDINGS.md`), `MAGNITUDE.md`, `ESTIMATE.md` | bare names that resolve nowhere are counted and listed only under `--bare` |

Every suppression is **counted and printed on every run**, per
`board_audit.sh`'s rule that a filter you cannot see is a filter you cannot
audit. `checked == 0` exits non-zero, per ROADMAP §9.18.8.

## 5. Found and not taken

Ranked by what a later lane would gain.

1. **The 39-finding citation backlog, in four classes.** Eight rung docs place
   `DISCLOSURE` at the top level of `docs/` when it lives under `whitebox/`;
   twelve `BOARD.md` rows plus one in `CFG_SHAPE.md` cite three 2026-08-05 rung
   files that are not in the tree; `ROADMAP.md` cites a front-end bundle
   document that does not exist, twice; eight `:NNN` point past the end of a
   since-shortened file. **Not fixed here**, for two reasons that are not the
   same reason: most sit inside **dated records**, which the structure order's
   own constraint says stay as written, and the two live files involved
   (`BOARD.md`, `ROADMAP.md`) are concurrent surfaces during a four-lane wave.
   A triage lane owns this, not a structure lane.
2. **Wiring the auditor into `scripts/gate.sh`.** Deliberately not done: a gate
   that is red on arrival trains people to bypass it. Two named routes — triage
   item 1, or add a `--baseline` mode so the gate reads *no new findings*. The
   second is perhaps 20 lines.
3. **The `README.md:252` class the auditor cannot help with.**
   `whitebox/READ_PLAN_2026-08-21.md` §5.4 cites a `README.md` that is the
   *Ghidra export's* README, outside this repo entirely. Bare basenames that
   mean a file in another tree are indistinguishable from broken ones; the only
   fix is at the writing end (`../ghidra/README.md`, or naming the tree).
4. **The auditor does not skip fenced code blocks**, so a document quoting a
   broken citation — including this rung quoting the auditor's own control
   output — trips it. Skipping fences is ~10 lines and was **not** taken here:
   it would change the finding baseline the identity check in §4 depends on,
   and a `cat docs/<NAME>` inside a fence is a real citation worth checking.
   A later lane should decide, not this one.
5. **Generated files drift by ENVIRONMENT and no instrument here sees it —
   board #3381.** `gen_rung_index.sh` sets no collation, and
   `rung_registry.rs` compares the file on disk against the script's output *in
   the same environment*, so both sides move together and the check cannot
   fail. Measured in this worktree: adding one rung changed **1** line under
   `en_US.UTF-8` (matching the committed file), while the same tree regenerated
   under `LC_ALL=C` differs in **56**. **Not fixed here** — the coordinator
   deferred it until the wave lands so four concurrent lanes do not each
   regenerate the index a different way. Recorded as a class in
   `DOC_CONVENTIONS.md` §4 instead, alongside a check a contributor can run
   (`git diff docs/rungs/INDEX.md` must show only your own row). The general
   shape is worth more than the instance: **"generated" is a claim about a
   command, and a command's output is a function of its environment.**
6. **`docs/whitebox/ref/README.md` says "19 `WB_*_FINDINGS.md` documents";
   the tree holds 18.** Counted 2026-08-22. Not edited — it is one word inside
   a live index, and the lane that owns `ref/` should decide whether the
   nineteenth was renamed or never landed.
7. **`docs/plan/` holds exactly one file and it is not documentation.**
   `CONTROL_TUS.txt` is `include_str!`-ed into
   `crates/c2-harness/src/gap/plan.rs` — it is *data* living in `docs/`, and a
   later lane may want it under `crates/` beside its consumer. **Measured, and
   the answer is that this is NOT the cheap move it looks like**: 25
   occurrences across 9 files — three `crates/` modules (`plan.rs`,
   `render.rs`, `factors.rs`, one of them an `include_str!` whose relative path
   is four `..` deep), two rung docs, `BOARD.md`, `STATUS.md`,
   `ARCHITECTURE_PROPOSAL_2026-08-20.md`, and now `README.md`. Two of those are
   dated records that must not be edited, so a move leaves them citing a path
   that no longer exists. Routed from `README.md` with the fact stated instead.

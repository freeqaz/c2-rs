## 3. What ships (#1960, #1961, #1962)

### 3.1 The production, and why it is a reader rung

```text
  seq := stmt_call+ tail                        (unchanged — BodyShape::CallSeq)
  stmt_call := ( 26 <callee> BD … )   4C 4B     free function   — ships today
             | ( 26 <method> B9 <recv> <ptr4> [2C <ptr4> 00] 99 <ptr4> 00 BD … )
                                      4C 4B     MEMBER CALL     — THIS LANE
```

`p->m(a…)` is `m(p, a…)`, so the receiver is appended to the argument list and
comes out of the shared marshalling as **slot 0** — exactly what
`mcall_tail::try_parse_member_tail_call` already does for the *tail* form and
what `member_tail_call_puts_this_in_slot_zero` already pins. Every word of the
emitted bodies was read off `work/w-mcall/probe/p2.obj` before a line was
written:

```text
  void mem2(S* s){ s->a(); s->b(); }
      mflr r12 · stw r12,-8(r1) · std r31,-16(r1) · stwu r1,-96(r1)
      mr r31,r3 · bl ?a · mr r3,r31 · bl ?b
      addi r1,r1,96 · lwz r12,-8(r1) · mtlr r12 · ld r31,-16(r1) · blr
```

That is the shipped Class B frame, and the free-function twin `void t(int a){
g1(a); g2(a); }` emits the same shape today (`work/w-mcall/probe/p3.cpp`,
`Port=Match`). **`crates/c2-core` is untouched.**

**There is no Class A two-member-call body**, and the rung turns on noticing it:
a member call needs its receiver, so the second call's receiver is live across
the first `bl` by construction. The class's *smallest* member is already Class B,
where the free-function sequence's smallest is Class A.

### 3.2 Two routes, because the reader enters from two places

* `mcall_tail::try_parse_member_tail_call` — this call is the **first**
  statement. Where the body did not end at the call it produced
  `prod_tag("tail-void-body-does-not-end-at-the-call")`; it now attempts
  `parse_call_sequence_from` with the member call as the prefix.
* `calls::parse_call_sequence_from` — this call is a **later** statement, reached
  through `parse_call_shape`. Its base census key for that exact body was
  `call-token-0xB9`.

A lane that shipped only the first would leave `void f(S* s){ free(); s->a(); }`
blocked, and the fixture's cell P6 is the witness.

### 3.3 The refusal direction, and why no key is re-keyed (clause D7)

`eat_member_stmt_call` is **atomic**: on any refusal the cursor is restored and
the caller re-raises the **free-function** reader's own `Err`, which is the block
every one of these bodies reports today. So the reader can only turn an `Err`
into an `Ok`. That is the mirror of w-value's acceptance theorem pointing the
other way, and like it, it is a **test** and not a comment:
`eat_member_stmt_call_restores_the_cursor_on_every_decline` enumerates all 256
receiver-byte values and every prefix of a real production, and asserts the
cursor lands back where it started — including from a non-zero start, so a
restore-to-zero would fail.

The **fence order** was frozen in `work/w-mcall/PREREG.md` §2 before the code:
the free reader goes first on a scratch cursor, and the member arm is tried only
when it has already refused. A free call and a member call share the `26 <tok>`
head, so an arm that guessed "member" first would have to un-read it.

### 3.5 A guard that is INERT, recorded as inert (#1963)

The sequence route is gated on `depth == BODY_SCOPE_DEPTH`, because the sequence
loop asks for the return plumbing at that depth and a braced body would be read
at the wrong one. **A scratch counterfactual replaced the condition with `true`

## 3. What ships

### 3.1 The class, in port terms, and exactly what CFG shapes it lowers

```c
    void f(unsigned n, const float *a, float *b) {
        if (n == 0)
            return;
        for (unsigned i = 0; i < n; i++) {
            b[i] += a[i];          // or  b[i] *= s;  or  c[i] = a[i] * b[i];
        }
    }
```

**One CFG shape, in three register plans.** The control-flow graph is the same
in all three: an entry block whose guard is realised as a *conditional return*,
a preheader, a single-block loop body, and a latch — `wb-loop`'s pass 1 and
pass 2 with no forward branch anywhere and no join. What differs between the
three is the **register plan and the store form**, and each is transcribed:

| sub-shape | statement | walker `r11` | park | store | witnesses | cell |
|---|---|---|---|---|---:|---|
| **A** `Compound` | `b[i] OP= a[i]` | `b` | `mr` **above** the guard | `stfs 0(r11)` + `addi` | 6 | `Add_InPlace`, `Mul_InPlace`, `c2`, `c7`, `c8`, `d5` |
| **B** `Scalar` | `b[i] OP= s` | `b`, biased −4 | `addi` **below** | **`stfsu 4(r11)`** | 4 | `MulConstant_InPlace`, `c12`, `d3`, `d4` |
| **C** `Binary` | `c[i] = a[i] OP b[i]` | **`b`**, the later-declared RHS array | `mr` **below** | `stfsx r9,r11` + `addi` | 4 | `Mul`, `c1`, `c6`, `d1` |

`OP ∈ { +, * }` and nothing else. The class is `/O1` only.

**It is NOT the block IR `docs/CFG_SHAPE.md` §6 specifies**, and the difference
is worth stating item by item, because the commission's name for this lane is
the spec's name:

| §6.2 item | this class |
|---|---|
| A blocks with an explicit order and terminators | **no** — one straight run of words |
| B labels resolved by a fixup pass | **no** — `codegen::labels` is untouched, its invariant 4 intact |
| C two branch encodings chosen by target kind | **no** — one `bdnz` |
| D a displacement range check with a defined expansion | inherited from `encode_bdnz`, which refuses rather than truncating |
| E a condition-code model with two producers | **no** — one `cmplwi` into `cr6` |
| **F values live across block boundaries** | **no**, and this is the item the spec calls the pivot |
| G a place to record the folds per accepted shape | the three sub-shapes, in one enum |

The back edge's displacement is computed in the emitter and never enters
`LabelMap`, which is the escape hatch `ptr_walk_loop` and `ptr_walk_chain_loop`
already use and which `codegen/labels.rs`'s own 2026-08-08 correction names.

## 7. `mmio.cpp` — the priced decline

Full table in `work/w-blockir/MMIO_PRICE.md`. **Eleven distinct unbuilt
mechanisms over three bodies**, in board #1418's unit (*"distinct clauses the
port names"*), which that row states is **not comparable** to
#483/#506/#827's seventeen (per-body independent refusals) nor to #2136's nine.

1. a framed prologue/epilogue at a 96-byte frame;
2. **the materialised common epilogue** — a forward join `Selected::Framed` has
   no representation for (board #506);
3. forward conditional branches on `cr6` inside a framed body;
4. the `.pdata` flag word, three different words for three bodies, computed
   rather than carried;
5. the coalesced two-register park;
6. **`memcpy`'s expansion cost model** — board #1925's *"MEASURED NON-RULE"*;
7. a callee-saved GPR live across a call — `CFG_SHAPE.md` §6.2 item **F**, the
   one item of the block-IR spec with no measurement behind it;
8. a second relational regime (`cmplw` on two loaded values, `bf 24`);
9. an **indirect call** (`lwz`/`mtctr`/`bctrl`);
10. `cr0` compares beside `cr6` ones in one body;
11. **an ELIDED CALL** — `mmioSetBuffer(hmmio,0,0,0)` is in the source and there
    is **no branch for it in the obj**, though the callee is
    `__declspec(noinline)` with a non-empty body.

Item 11 is `w-readpx` §5.2's inlined-callee hazard made concrete: the port would
emit a `bl` that c2 does not. `elide.rs`'s mechanism E is a *tail* call to an
*empty* body and does not reach it.

**The inlined-callee check on the class this lane DID ship**: it admits no
call-bearing body at all — shapes A, B and C are leaf loops with zero call edges
— and `IPP_basicmath_xbox.cpp`'s obj carries **zero relocations** in all four
`.text` sections. The named hazard is structurally absent, checked against the
obj's own relocation count rather than asserted.

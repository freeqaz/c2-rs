### 2.1 The seeding predicate, as shipped

`no_effect_nothing(seg) -> bool` — the third reader in `no_effect.rs` and the
first that returns a `bool` rather than a callee token, **because the body it
reads has no callee**. It accepts a segment whose whole content, walked
**totally** from the body marker to `eat_return_plumbing`'s fail-closed terminal,
is the body scope with nothing deeper, one line marker, `33 <INT_TYPE> <v>`,
`33 82 07 <id> <v>`, `44`, `4B`, a line marker, and the return plumbing.

Four things make it a claim rather than a guess:

1. **The walk is TOTAL.** Every byte of the segment is consumed by a production
   above, so *"there is nothing else in this body"* is structural and not a
   search. Mutation **M1** removes the terminal and two named tests go red.
2. **The vocabulary is CLOSED and contains NO CALL TOKEN.** `26` (which is also
   the data-symbol push), `B9`, `BD`, `40`, `4C`, `67`, `9B` and every label
   opcode are outside it, so a body this accepts **names no callee and
   materializes no data symbol**. That is what licenses `link = None`, and §5 is
   why it is the *reader* and not that arm that enforces it. Mutation **M2**.
3. **The literal TYPES are pinned and the literal VALUES are not.** A literal is
   pure whatever its value and the statement is discarded, so the value cannot
   change what is emitted; constraining it would be **#644**'s mistake, the one
   `no_effect_call`'s align/count/fill deliberately avoid. The **type** is a
   soundness constraint: a `float`/`double` literal drags `_fltused` into the TU
   and the obj **grows a symbol** — `CallRet::discarded`'s reason, one operand
   over. The void type's **id** is not constrained either; it is a per-TU
   type-table index.
4. **`44` is consumed as a BYTE, not as an operator whose arity this module claims
   to know.** `eat_dead_temp_arg` reads the same opcode after exactly one operand
   and this statement carries two before it; nothing depends on resolving that,
   because the statement is pinned as a sequence and any deviation refuses.

**`parse_segment` is byte-for-byte unchanged**, the row stays
`FnVerdict::Blocked`, still `fnbyte-refused` **130,579** at both ends, and
`IlBundle::functions` still refuses its whole TU. #971 condition 4, satisfied by
construction.

## 5. THE CYCLE ARGUMENT, RE-DERIVED — and M3a is the sharpest row in the lane

`w-fix` #950 argued *"a cycle is never **seeded**, so it is never admitted"*. That
sentence was true **because `empty_body` was the only seed**, so it does not
survive a widening of the seed set on its own authority. `PREREG.md` §0.3
registered the re-derivation in advance, in four steps:

1. **Termination is untouched.** A name is admitted only on a `false → true`
   transition, so a productive round admits at least one of finitely many names.
   That argument reads the **step**, not the seed set. The round ceiling stays.
2. **A seeded name has no outgoing link**, because the reader's vocabulary
   excludes every call token.
3. **Admission propagates only backwards along links, from a seed**; following
   links out of a cycle stays inside the cycle forever.
4. **A cycle member cannot seed**, since membership requires an outgoing link.

∴ no cycle member is admitted. `a_cycle_is_not_elided_and_terminates` and
`the_round_ceiling_cannot_fire` are untouched and still pass; GRID-N's `n06` is
the compiled cell; `a_cycle_of_refused_links_beside_a_seed_admits_only_the_chain`
is the new one.

| # | guard removed | result |
|---|---|---|
| **M1** | the totality terminal | **RED**, 2 named tests |
| **M2** | the reader's closed vocabulary — accept any statement | **RED**, 6 named tests |
| **M3a** | give `NoEffectNothing` a link as well as a seed | **GREEN** |
| **M3b** | make `NoEffectCall` seed as well as link | **RED**, 2 named tests, including the cycle one |

> **M3a IS THE ROW TO READ.** Step (2) says a seeded name carries no outgoing
> link, and the obvious reading is that `link = None` in `of_rows` is what
> enforces it. **It is not.** The iteration skips a name already in `in_r`
> (`if in_r[i] { continue; }`), so a seeded name is **never asked for its link at
> all** and that arm is inert as the loop is written. Putting a link there changes
> nothing and no test can see it.

The enforcement is the **reader** — `no_effect_nothing` refuses every body with a
call token in it — and the fact that `NoEffectCall` does **not** seed. Both doc
sites are corrected in place, because the old wording is a licence a later lane
would cite to weaken the vocabulary on the grounds that *"`elide.rs` sets the link
to `None` anyway"*. It cannot save you.

**M3a is reported green rather than rewritten until it went red.** A mutation
edited to fail proves nothing, which is the whole reason the registration is
written down before the run. Board **#1088**.

## 7. THE FINDING — the census key is the first blocking feature, not a description of the body

`fnbyte-nothing-key-expr-lit-type-8207` is **4,156** and
`fnbyte-nothing-key-param-width-undetermined:mid` is **10**. The prereg registered
that a second key here *"is a body the grid never saw and is a finding, not a
bonus"*, so it was read rather than reasoned about (`work/w-seed/findkey.sh`).

The ten are the **same** `??$__destroy_aux@…` production at the same 115-byte
segment length — `??$__destroy_aux@UInstance@RndMultiMesh@@…`,
`??$__destroy_aux@VVector2@@…` and eight more. `parse_segment` blocked in the
**formals** region and never reached the body, so the key records *where the
parser stopped* and not *what the function does*.

**They converted nothing**, and that is measured rather than argued: they extended
**7** no-effect chains (`fnbyte-noeffect-stop-param-width-undetermined:mid`
80 → 73) and produced **zero** elisions, because 227 − 4 = 223 = 232 − 9 accounts
for every conversion through the `expr-lit-type-8207` route alone, and
`fnbyte-elided` = `-elided-exact` = **1,877** is +223 exactly.

The consequence for the next lane is about instruments, not about this rule: **a
stop histogram keyed on the census verdict does not partition the same way a
body-keyed reader does**, so a body rung sized off a key histogram is sized off a
different question. Board **#1091**.

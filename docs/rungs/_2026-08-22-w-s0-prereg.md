## 0. What is frozen here, and what is not

**Frozen:** everything below — the re-measured baseline, the instrument's shape,
the key names, the partition and its controls, the relaxation ladder as a named
enumerable parameter, the predictions with their thresholds, the incumbent each
number must beat, the decision rule, and — most importantly — **§6, the reading

whatever **relaxed-decode entry** it needs in `crates/c2-il/src/func/`. It does
**NOT** touch `crates/c2-core/src/codegen/` select/lowering/encode (peer lane
`w-s1`) or `crates/c2-core/src/coff/label.rs` (peer lane `w-seedgap`). If the
relaxed decode forces an edit into either, the lane **STOPS and reports the
collision** rather than editing.

## 2. What the instrument is

A new module, `crates/c2-harness/src/gap/blind.rs`, run from the same
denominator-driven walk FBM uses (`gap/fnbytes.rs`), over the **parse-refused**
subset only:

1. **Population.** Iterate the reference obj's `.text` COMDAT leaders. Select
   those whose FBM verdict is `Refused` with a **parse** decline — the census
   row's `IlFunction` is `Err`, so `select_function` was never called.
2. **Relaxed decode.** Run a *relaxation ladder* (§3) over the same `.ex`
   segment the strict parser refused, producing a candidate `IlFunction` or
   nothing.
3. **The one composition.** Feed the candidate to `codegen::select_function`
   then `c2_core::comdat::comdat_function_body` — **called, never copied**, for
   the reason `fnbytes.rs:98` gives: a reconstruction here would drift from the
   emitter and an alarm that is green about bytes the port does not emit is
   worse than the blind one it replaced.
4. **Grade against real c2.** Byte-compare the composed body against that
   COMDAT's own raw bytes. The judge is c2, exactly as in `CLAUDE.md`.

### 2.1 Keys — all NEW, none shared

`fnbyte-blind-*` is verified unused anywhere in `crates/`, `scripts/` or
`docs/` before this commit. **No existing key or predicate is narrowed, widened
or redefined** — in particular `FnByte::Exact`, `fnbyte-exact`,
`fnbyte-refused-parse` and `comdat_function_body` are read-only to this lane.

| key | is |
|---|---|
| `fnbyte-blind-attempted` | the parse-refused population the walk offered to the relaxed decode |
| `fnbyte-blind-exact` | relaxed decode + the one composition produced bytes **identical** to c2's COMDAT |
| `fnbyte-blind-differs` | produced complete bytes, and they **differ** |
| `fnbyte-blind-unlowerable` | produced no bytes at all |
| `fnbyte-blind-unlowerable\|<why>` | …split by which stage refused: `no-decode` · `no-select` · `no-compose` · `no-refbytes` |
| `fnbyte-blind-level` | the ladder depth this scan ran at (§3) |
| `fnbyte-blind-partition-broken` | **known answer 0** — `exact + differs + unlowerable != attempted` |
| `fnbyte-blind-population-broken` | **known answer 0** — `attempted != fnbyte-refused-parse` |

### 2.2 It obeys FBM §0's separation rule verbatim, and that is non-negotiable

`docs/FUNCTION_BYTE_MATCH.md` §0 is the standing template for every gradient
added after FBM, and §0's 2026-08-22 banner names S0 by name as one of the two
extensions on the books. All five properties are adopted:

* **Never in `scripts/gate.sh`**, and must never be added there.
* **Its own block**, under its own disclaimer, apart from the class table that
  carries `match`/`mismatch`.
* **Namespaced keys** — `fnbyte-blind-*`.
* **Licenses no emit.** `blind-exact` going up is not a reason to accept a
  shape, to widen `IlBundle::functions()`, or to admit anything. The only thing
  that accepts a shape is the differential.
* **Unrepresentable over an empty scan** — `NO-RESULT`, no key, never a ratio
  over zero.

### 2.3 A positive check, never an absence

`ROADMAP_SLICING` §6 rule 4 and the brief's standing rule. Concretely:

* `fnbyte-blind-attempted` is **printed**, and a scan whose `attempted` is 0
  prints `NO-RESULT` and **fails the lane's own evidence bar** — it is not
  reported as "`blind-differs` 0".
* `fnbyte-blind-population-broken` is a *positive* cross-check that the walk
  reached the same 113,557 functions `fnbyte-refused-parse` counts, computed in
  the same loop iteration rather than by subtracting two published totals
  (`fnbytes.rs:1522`'s rule, which exists because `emit_blockers` was read as a
  codegen reading it never was — #1464).
* **The L0 identity control (§3) is the instrument's own known-answer test**: at
  ladder depth 0 the relaxed decode is the strict decode, so the required answer
  is `exact 0 · differs 0 · unlowerable == attempted`, **all under
  `no-decode`**. A nonzero `blind-exact` at L0 means the walk is grading
  something other than the parse-refused population, and is an alarm.

## 3. The relaxation ladder — a NAMED, ENUMERABLE PARAMETER, not a baked constant

`docs/GOAL_DECISION_2026-08-21.md` § AMENDED and `ROADMAP_SLICING` §6 rule 7:
every general layer ships its arbitrary choices as named, settable parameters.
The ladder depth is one such choice and is exposed as **`C2RS_BLIND_LEVEL`**,
enumerable, with every level printed in the report whether or not it fired.

| level | name | relaxes |
|---:|---|---|
| **0** | `strict` | nothing — the identity control. Must reproduce `unlowerable == attempted`, all `no-decode`. |
| **1** | `name-from-obj` | the post-parse **symbol-resolution** gates. A body whose whole-segment grammar was accepted and which was blocked only because a callee / data symbol / function name did not resolve through `.gl` is given its name from the reference obj's own COMDAT leader. |
| **2** | `formals-width` | the `.sy` formals-width precondition (`body/mod.rs:~1985`), by assuming one register per formal — **the assumption `GAPS.md` §6 records as WRONG.** Its `blind-differs` is therefore a *measurement of how wrong*, and that is the point. |

**Level 1's name substitution changes no byte and this is load-bearing.** Under
`/Gy` every function starts at offset 0 of its own section and a call word
carries a placeholder displacement, so the callee's identity lives in the
**relocation record**, not in the instruction word (`w-drop3`, #984–#989, and
`fnbytes.rs`'s `port_call_targets` doc). So:

> **BLIND GRADES BYTES ONLY. It does not grade relocations, and it will not
> publish a relocation verdict.** A level-1 body's relocations are against a
> name taken from c2's obj, so a relocation grade there would be circular. This
> is stated in the printed disclaimer, not only here.

**Why the ladder stops at 2 in this lane, stated in advance.** The measured
widening order over the refused population (`base_scan.log:1765`) is dominated
by *expression-operand vocabulary*, not by acceptance gates: `expr-op-0x27`
22,310 (19.6 %), `expr-intrinsic-this-adjust` 9,278, `expr-intrinsic-base-member-addr`
6,477, `expr-call-in-expr-*` ≈ 14,000, `body-0x9B` 2,211. Those are
`ROADMAP_SLICING` §3's ten named constructs — **Phase 1 slices C1–C10, each
priced 2–4 wk raw on its own.** A ladder level for any of them is a Phase 1
slice wearing an instrument's clothes, and pricing one inside S0 would repeat
exactly the error §5's encoder row corrects (three jobs priced as one). **S0
ships the frame and the ladder; the constructs are C1–C10 and are not this
lane's to build.**

## 5. Decision rule

* **`instrument`** — the frame lands, the partition and both controls read their
  known answers, the identity holds, and the population is graded. This is the
  expected outcome and it does not require any particular blind number.
* **`declined`** — the relaxed decode cannot be built without entering `w-s1`'s
  or `w-seedgap`'s seam. Priced and reported; a priced decline is a good
  outcome.
* **`FAILED`** — in these words, if the lane produces no graded population: if
  `attempted` is 0, or `partition-broken`/`population-broken` is nonzero and
  unrepaired, or the identity moves. **A run that graded nothing is a loud
  failure, not "`blind-differs` 0".**
* **A `mismatch` anywhere is an alarm outranking all of this**, and the lane
  stops and reports it.

## 6. THE READING RULE — which of §5's three outcomes I may declare, and which I may NOT

`ROADMAP_SLICING_2026-08-21.md` §5 registers three readings of S0, and one of
them (**`S0 ≈ 0` → "the halves are not separable, 15–45 months is optimistic"**)
is a finding that argues for *stopping or re-pricing the program*. A finding
that consequential must not be manufacturable by shipping a weak instrument.
So, frozen in advance:

1. **A small `blind-exact` at a shallow ladder depth is NOT the `S0 ≈ 0`
   reading.** §5's `≈ 0` outcome is a statement about *a general decode*. This
   lane's ladder is explicitly **not** a general decode (§3): it relaxes
   acceptance gates and leaves all ten of §3's constructs unimplemented. If
   P3 holds — reach < 5 % — then **the instrument has not asked §5's question
   yet**, and I will say exactly that, in those words, and decline all three
   readings.
2. **The reading is licensed only on the reached sub-population, and only with
   its denominator in the same sentence**, and it is a statement about *that
   sub-population's refusal classes*, never about the 113,557.
3. **A frozen holdout is only as good as the classes it happens to contain.**
   The rung doc will enumerate, by name, which refusal classes the reached
   sub-population contains and which of the 594+ distinct blocking features it
   does not, so absence is never read as coverage.
4. **`blind-differs` is the one number that prices something immediately even at
   shallow depth** — it is a direct count of wrong emits the corresponding
   `functions()` widening would ship, per §5's third reading and §6 rule 2's
   two-sided pricing. That reading **is** licensed at whatever depth is reached,
   because it is a statement about the bodies actually graded. It still carries
   its denominator.

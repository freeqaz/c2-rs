### 9.1 This does NOT overturn `w-fence163`'s `+163`

Stated explicitly, because the row bears on evidence that is already merged and
the distinction is easy to lose.

`w-fence163` §3/§9's acceptance evidence reads *"`fnbyte-differs` 1,958 → 1,958,
identical **PER SYMBOL**: 0 new, 0 gone, set-compared over both
`--fnbyte-diff-jsonl` dumps, not by subtracting totals."* The comparator behind
that sentence is the one this section finds unsound. **The `+163` still stands**,
on two independent grounds:

1. **Its attribution was laddered, not paired.** fence163 measured four rungs
   (F1–F4) and *two of them moved the graded column by exactly zero*
   (§7.1's table). A ladder in which the null rungs are measured is evidence the
   per-symbol comparator plays no part in.
2. **Its population barely moved.** fence163's change took `fnbyte-differs` from
   1,958 to 1,958 — the admitted set moved by 163 bodies out of 162,046, and the
   relabelling this section describes is driven by *which segments the census
   keeps*. A comparator that is unstable under population change is least likely
   to mislead when the population is nearly fixed, which is that lane's case and
   is emphatically not this one's.

**What is NOT sound is the comparator as a STANDING acceptance test.** It should
not be used again — by any lane, or by `docs/STATUS.md`'s warranty prose — until
it is keyed name-stably. The correct key is per-TU multiset of
`(shape, port_words, ref_words, sub, ins, del)`, or a `.gl` per-record name
rather than `Bindings::positional`. **Here it failed loud; the same instability
is silent in the other direction**, and a standing test that can be silently
wrong is worse than no test, because it is quoted as warranty.

The consequence bites in the dangerous direction too. Here the name key was
fail-**loud** — it invented three wrong bodies that did not exist. The same
instability can relabel a *genuinely* new wrong body onto a name already in the
base set, where it reads as **0 new** and is invisible. **A per-symbol set
compare is sound only for a change that does not move the admitted population —
which is the one situation in which nobody needs to run it.**

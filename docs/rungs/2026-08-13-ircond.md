### 1.0 The success criterion, stated before the claims

**Required-zero byte delta.** This lane converts zero TUs *by design*. A
conversion would mean behaviour changed, which is the failure mode, not the
prize. Grading is a line-for-line identity diff of the 878-TU scan's
`gap-metric` keys and of every gate lane's fixture-verdict counts, base against
tip. **Any byte that moved = FAILED**, whatever else the lane achieved.

Absence is not the check. Every row below is graded **positively on content**:
the scan must print its `gap-metric` block and be digit-for-digit equal; the
gate must print `graded > 0` per lane and the per-lane counts must be equal; the
workspace run must print a pass count **and** a target count. A missing number
is a MISS, never a zero.

### 1.2 Predicted NOT to change, named so the diff can be read

* No consumer of `CondPairParts` changes: `codegen::select::Selected::CondPair`,
  `c2_core::lib.rs`'s packed emitter and `c2_core::comdat.rs`'s `/Gy` emitter
  keep reading `{ text, branch_offsets: [u32; 2] }` unaltered. The IR is *how
  the parts are built*, not a new boundary.
* `crates/c2-core/src/coff.rs` is **not touched** — single-occupancy, and it
  holds the compiler-label counter.
* `crates/c2-harness` is **not touched** — peer lane `w-fencecount` owns it.
* No existing predicate is narrowed, shadowed or redefined. In particular
  `codegen::labels::{LabelMap, Label, Form}` (board **#290**, §6.2 item **B**)
  is the **existing reader** of "a pending intra-section branch site and its
  target". This lane **uses** it and builds no second one. `Form` deliberately
  has **no external variant** (#191/#290) and that stays true.

### 1.3 Anti-collision check, done before the first type was named

1. `c2_il::Block` **already exists and is public** — the census *blocking
   record* (`crates/c2-il/src/func/body/mod.rs:1088`), re-exported from
   `c2_il`'s root and used across `crates/c2-core`. A `Block` in
   `c2_core::codegen` glob-re-exported through `codegen/mod.rs`'s
   `pub use <module>::*;` convention would put two `Block`s in ambient scope.
   **Mitigation, frozen here:** the type is named **`BasicBlock`**, and the new
   module is **NOT** glob-re-exported.
2. `LabelMap`/`Label`/`Form` exist and are the fixup mechanism. No second fixup
   list, no second label identity, no second forward-branch rule.
3. No `Terminator`, no `BlockId`, no CFG type exists anywhere in `crates/`
   (grepped at base). Those names are free.

### 1.4 Bounds (`CFG_SHAPE.md` §6.3), all binding

No code motion; no cost model; no loop rotation; no CTR-loop discovery; **no
instruction scheduler** — sibling lane `w-dagorder` has just shown c2 runs a
cycle-driven dependence-DAG list scheduler, which is item **F**, is much larger
than board #1823 priced it, and is explicitly not this lane's; no neutrality or
behaviour-preservation classifier. The IR is built so a scheduler *could later*
be expressed over it; no order is assumed beyond the one the already-byte-exact
class produces today. Items **E**, **F** and **G** stay absent at tip; this lane
builds item **A** only.

### 1.5 How a FAILED outcome is reported

If any byte moved, the header says `Outcome: FAILED`, in that word, with the
moved byte named — not a compound headline, and no rationalisation.

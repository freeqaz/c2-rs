## 2. `INLINE-P`, and how it was graded

### 2.1 The instrument — and why a one-sided obj grade is not a grade

§6.15's own observable is: *an inlined call leaves no trace in the caller's
relocation table; a declined one leaves exactly one REL24 against the callee's
symbol.* From an obj alone that shows the **declines** and cannot show the
**inlines**, so a rule graded on it is improved by predicting `DECLINED`
everywhere. The lane's first pass did exactly that and its numbers are void as a
grade (they survive as `scan_obj.py`'s falsifier and nothing more).

The fix is a second real compilation: **the same TU, the same workload flags,
`/Ob0` appended.** Inline expansion off, so every source-level call to a same-TU
function leaves a REL24 and `n_sites(G)` is measured by the compiler.
`work/w-inline/grade_pair.py`. Board **#905**.

**The enumerator has a positive control and it can go red.**
`work/w-inline/ctl_ob0.py` p4 — `int g(int a){ return a+1; }` — must show **no**
internal REL24 at `/O1` and **exactly one** at `/Ob0`. It does. Without that row
every `INLINED-ALL` in this rung could be a call that was never there.

Three confounds, handled in the file's own doc rather than in prose:

1. **Funclet names do not survive a recompile.** `__unwind$104392` is a
   compilation-local counter. Excluded from both sides.
2. **Inlining MIGRATES call sites.** 158 of `Utl.cpp`'s `/O1` internal edges do
   not exist at `/Ob0`: c2 inlined `H` into `F` and `H`'s own un-inlined calls
   came with it. The grade is aggregated **per callee**, never per pair.
3. **`/Ob0` is a different compilation.** Every `INLINE-P` input is read from the
   `/O1` obj. `/Ob0` is used for one thing: counting REL24s to a name.

## 4. The one input nothing can supply — and the port is the exception

§6.19.6 already said the index is *"a post-allocation byte count, minus 48 for a
predicate that is false in the emitted code and true only upstream of it."* This
lane is that sentence costing something.

| leaf bit derived from | SAMPLE-B | GRID-2b |
|---|---:|---:|
| the `/O1` obj | 0.9631 | **0.9980** |
| dropped entirely (**frozen by addendum 2**) | **0.9716** | 0.8401 |
| the `/Ob0` obj (source-leaf) | 0.9688 | 0.9980 |

**The term is real** — GRID-2b's ladders step at `s = 112/116`, which is
64/68 **+ 48** exactly. **And no compilation supplies its input**: `/O1`
over-reports leaf (a callee whose own calls were inlined away reads leaf);
`/Ob0` under-reports it (c2 decides bottom-up, so a callee's own inlinable calls
are gone by the time it is priced). The truth is between the two and is
**NOT MODELLED**. Board **#900**.

**The IL has it.** The bundle carries the callee's un-lowered body, so a
recognizer can ask *"does this body contain a call"* directly. This is the one
input where the port is better placed than any obj-side instrument, including
every one in this rung.

## 5. THE FINDING — family A is not inlining, and #877's decline is re-priced

`work/w-inline/ctl_ob0.py`, at the workload's own flags, with and without
`/Ob0`:

| probe | callee | callee emits | `/O1` call | `/Ob0` call |
|---|---|---|---|---|
| p2 (`w-fnbyte`'s own probe) | `void g() {}` | `blr` | — | **—** |
| p8 | `void g(int a) {}` | `blr` | — | **—** |
| p3, p5 | a trivial `~B()` over a trivial `~A()` | `blr` | — | **—** |
| **p6** | `int g(int a) { return a; }` | **`blr`** | — | **`bl ?g` ✔** |
| p4 (**positive control**) | `int g(int a) { return a + 1; }` | 2 words | — | `bl ?g` ✔ |

**p6 against p2 is the discriminator**: byte-identical emitted callees, opposite
verdicts under `/Ob0`. The elision reads the callee's **source** body, and it is
**not governed by `/Ob` at all** — so it is not inline expansion.

Retrodicted over 120 sampled TUs against the standing instrument's own
`fnbyte-differs-fn` witness keys:

```
  FAMILY A          532 of 532 callers have NO same-TU callee even at /Ob0
  everything else   687 of 687 pairs, 681 of 681 callers, HIT
```

Board **#896** (REFUTED) and **#897**. `w-fnbyte` §8.1 declined the cheap repair
because *"the predicate ('c2 will inline this') is a **cost model**, not a
syntactic fact"* — right about mechanism I, wrong about the family it was
applied to. `IlBundle` already carries a special case of the correct rule:
`eh_unwind_callees` accounts the base destructor an empty constructor names,
*"on the cheap side there is no funclet, so c2 emits no `bl`, no relocation and
no symbol for it"*.

**And it is still not taken here.** `PREREG.md` §5's second floor forbids this
lane shipping a port change, for the same reason `w-fnbyte` gave: the lane that
found the defect is the wrong lane to narrow acceptance in.

## 8. Found and not taken

1. **Mechanism E is the cheapest thing on the 4,711's work list and it is a
   `c2-il` fact.** *A call edge whose callee is defined in this bundle and whose
   IL body is empty emits no branch, no REL24 and no external symbol.* Up to
   **1,886** functions, emitter untouched, no size and no cost model. Not taken:
   `PREREG.md` §5's second floor, and E's exact source predicate is bounded by
   three probes (`INLINE_PREDICATE.md` §1).
2. **Mechanism I has an ordering constraint that makes it expensive.**
   `INLINE-P` is indexed on the callee's **own emitted size**, so the port must
   be able to lower `G` before it can decide whether to inline `G` into `F`.
3. **`leaf`'s true input** (§4) is the largest single lever on `INLINE-P`'s
   workload residual and no compilation supplies it. The IL does.
4. **`scripts/gt_inline_decline.py` has never been run at `/EHsc`.** Every
   §6.15–§6.20 capture is `/O1 /GS- /c`. Board #901 is one consequence; whether
   any *other* §6 negative is flag-conditional is unmeasured, and `w-spell`'s
   #895 is the template for answering it in one run.
5. **The residual's shape is published and unfitted** (§6.1) — 155 of SAMPLE-A's
   294 misses are `operator`s, which no axis in §6.15–§6.20 distinguishes.

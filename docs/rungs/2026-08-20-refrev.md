**The `--test X` caveat is restated because this lane iterated that way all

those words when it closed the suite-level half.

## 1. §2.4 — the dead accessor, and why deleting it was the honest half

`CaptureCache::header_closure_warning` had **no caller in `src/` or `tests/`**,
and the module doc said the missing guard *"says so out loud"*. Nothing has ever
said it.

Wiring it was the tempting fix and it is the wrong one, which is the finding
worth keeping. `CaptureCache::new`'s `workload_dir` is `None` for **`c2rs
diff`** — deliberately, because that command's inputs are the self-contained
`fixtures/cpp/*.cpp`, which include no project headers, so their own bytes *are*
the closure. Wiring the warning would therefore have printed a staleness banner
on every fixture diff, on the one caller for which the closure is irrelevant,
while the caller that needs it (`c2rs gap`, which passes the workload `--cwd`)
was already correct. A guard that fires only where it does not apply is worse
than no guard; it teaches readers to skip a line.

Deleted, with the `header_closure: bool` field it read, and the module
paragraph rewritten to say what is true. The `no-git` state remains readable
where it actually lives — the `tree <token>` line of the key material.

## 2. §2.1 — one capture arm, graded on the rows

The two copies of

```rust
match cache { Some(c) => c.capture(…), None => tc.capture_reference_with(…) }
```

are now `capture_cache::capture_via`. The only behavioural motion is inside
`differential_cached`, and it is none: the profile resolution and the source
argument are computed once for both arms instead of once in the cached arm and
once inside `capture_fixture_reference`. Those were already the same
computation — `capture_reference_flags` is `to_wibo_path(absolute(cpp))`, and
`absolute()` on an existing path **is** `canonicalize()`
(`c2-reference/src/lib.rs:1463`). Same order (profile first), same string, and
the same error text for an unreadable `cpp`, because
`io::Error::new(InvalidData, e.to_string())` displays as `e.to_string()`.

**Identity protocol** (`work/w-refrev/`, base binary built from `826ba1e413`'s
`cli/` and kept as `base/c2rs-base`):

| run | base | tip | verdict |
|---|---|---|---|
| `gap` 40 fixtures, `--jobs 1`, cold | 0 hit / 40 miss | 0 hit / 40 miss | 40 TU JSONL rows byte-identical |
| `gap` 40 fixtures, warm | 40 hit / 0 miss | 40 hit / 0 miss | byte-identical |
| `gap` 40 fixtures, `--no-cache` | — | — | byte-identical |
| `gap`, **tip reading the cache the base binary filled** | — | 40 hit / 0 miss | byte-identical — the keys did not move |
| `c2rs diff` × 25 fixtures, cold / warm / `--no-cache` | — | — | 25 lines byte-identical, verdict *and* cache word |
| `c2rs diff` × 25, **tip over the base-filled cache** | — | 25/25 `cache=hit` | byte-identical |

Two fields are normalized in the comparison and nowhere else: the JSONL
`{"record":"provenance"…}` row and the two stdout provenance lines carrying the
binary's sha and the checkout's dirty bit. They differ *because these are
different binaries*; every per-TU row, every count and every cache counter is
compared byte for byte. `--jobs 1` is used because the per-TU progress lines are
emitted in worker-completion order, which is a property of the scheduler and not
of the code — a fact this lane established by diffing two base runs against each
other before diffing base against tip.

## 3. §2.2 — fifteen skip sites, and the demand that now reaches them

`toolchain_ready(&tc, &[Cap::…], "why")` replaces fifteen hand-written blocks
across six `cli/` modules. The rendering `SKIP: <capabilities> absent (<why>)`
is what all fifteen already used, including the part that looks like a bug and
is not: they name the capabilities the command **requires**, never the subset
actually missing, so `perf` says `strace / i686-w64-mingw32-gcc absent` when
either is gone. Preserved verbatim — five scripts scrape these lines.

**The skip lines are graded live, not by reading the diff.** A probe drives all
fifteen by pointing `C2RS_STRACE` / `C2RS_MINGW` / `C2RS_C1XX_DLL` at a path
that does not exist: nothing is deleted, `Toolchain::locate()` still succeeds,
so the guard under test is the capability guard and not the locate guard. Base
binary vs tip binary: **15 lines, diff empty.**

The new behaviour, demonstrated in three environments:

| run | binary | environment | result |
|---|---|---|---|
| M1 | **base** | `C2RS_REQUIRE_TOOLCHAIN=1`, caps absent | all 15 **exit 0** printing `SKIP` — the defect |
| M2 | tip | same | all 15 **exit 1** printing `REFUSED` |
| M3 | tip | `C2RS_REQUIRE_TOOLCHAIN=0`, caps absent | all 15 exit 0 printing `SKIP` — the portable entitlement survives an explicit opt-out |

Three details, each with a reason rather than a preference:

* **The refusal message does not contain the word `SKIP`.** `mode_lane.sh:64`
  treats a `SKIP` anywhere on that stream as *"toolchain absent, the row is
  vacuous, exit 0"*, which is the exact opposite of what a refusal means. A
  refusal that scraped as a skip would have been a new false green shipped
  inside a fix for false greens.
* **`CLAUDE.md`'s hard constraint is intact, and the boundary is exact.**
  `Args::toolchain`'s `SKIP: toolchain absent` — the line `CLAUDE.md` names — is
  **not touched** and still exits 0 under every environment. What can now fail is
  a *partially* provisioned run, and only when the caller has explicitly claimed
  the run grades.
* **`require_toolchain.rs` imports the rule instead of re-typing it.** Two
  implementations of "is the demand set" is the shape this funnel exists to
  remove; its behaviour and every line it prints are unchanged.

## 4. §3.2 — the flags constant was the item that mattered

Fourteen files each spelled `["/nologo","/wd4355","/wd4164","/c","/GR","/O1",
"/Oi","/EHsc"]`, and each spelling decides **which compiler that file's cells are
graded under**: `/O1` implies `/Gy`, so each function gets its own COMDAT
`.text`; a cell captured at `/Ox` produces a packed obj in which every
per-function assertion over it passes **vacuously**. A profile move that misses
a copy keeps grading the old mode and reads green — the absence family wearing a
flags list. Occurrences under `crates/`: **14 → 1**.

The constant is checked **against the workload**, not against a second copy of
itself: `workload_flags_are_the_workload_s_flags_in_order` reads
`work/dc3-workload/flags.txt`, strips the `/I <path>` pairs a standalone cell
cannot use, and compares element for element. That file is generated and not
tracked, so the test says so and returns when it is absent — the only honest
option for the portable lane, and a positive check on content when it is there.

`fn work(tag)`: 21 of 23 copies delegate, to **three** helpers kept distinct
because the difference between them is a paid-for lesson — `scratch_dir` is
stable per `(prefix, tag, process)`, and board #1045 is a *fabricated finding*
produced by four parallel tests sharing one such directory.

### What §3.2 asked for and this lane declined, with the price

* **The 146 `SKIP: toolchain absent` early-returns in tests are not converted.**
  §8 row 5 names 14 + 24 conversions and not these. The price of converting
  them: 146 mechanical edits across 30 targets whose only gain is uniformity —
  the demand they would carry is already total at the level that variable
  operates (`locate()` returning `None` fails the whole suite on the sentinel),
  so the conversion buys no warranty. The price of *not* converting them, which
  is the side that must also be counted: a future per-test demand mode would have
  to be added at 146 sites. That cost is real and it is deferred, not avoided.
  The half-measure — converting some — was rejected outright: it produces two
  implementations, which is the defect this lane exists to remove.
* **The four `grade_cell` copies are untouched.** #1094 owns that migration and
  the reasoning is recorded at `tests/cellgrade/mod.rs:1-22`. §7 item 5 is
  binding and this review does not override it.
* **The two `fn work` copies in `crates/c2-reference/tests/` cannot be
  converted.** `c2-harness` depends on `c2-reference`; the helper is not visible
  there without inverting the dependency for a six-line saving.
* **Steps 6, 7 and 8 are out of scope by dispatch** and stay open: the
  bench/selftest engine merge needs a quiet-box re-time (§3.4 warns the floor has
  already moved), the `gate-verdict` port is its own multi-day lane, and the
  provenance banners are prose.

## Found and not taken

   which would make the CLI's demand total rather than partial-provisioning-only.
   One line. Not taken here because it changes the sentence `CLAUDE.md` names as

   already drives `diff` over generated cells, and those are self-contained
   today. Worth a line in `capture_cache`'s docs if that ever changes; it now
   has one.
3. **The `SKIP:` rendering is a scraped stdout contract with no schema.** This
   lane pinned eight renderings in a unit test, which is the first thing that
   has ever checked them. §4.1's `gate-verdict` port is the real answer.

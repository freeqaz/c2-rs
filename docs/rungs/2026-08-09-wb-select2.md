## 0. What this lane was asked and what it found

WB-D §9.1 ended with *"a correct register policy assigns correct registers to
the wrong instructions until the pattern set is right"*, and WB-H §9 item 3
called the pattern set **"the only 'no' left"**. This lane was commissioned to
read it.

**It is not a "no" any more.** Instruction selection in this c2 is:

* **one machine-opcode table** — `0x10b1b260`, 12-byte records
  `{mnemonic, operand_format, attributes}`, index = c2's opcode number, real
  PPC mnemonics in **alphabetical order** and ~40 **pseudo-ops** after them;
* **thirteen per-operator opcode tables** of 26 entries each, installed by
  `FUN_10c04cb9` @ `0x10c04cb9`, indexed by an operand **type index**;
* **one dispatch** — `FUN_10c0f882` @ `0x10c0f882`, 174 tuple opcodes,
  **41 distinct arms**, for everything including VMX and floating point;
* **one idiom layer**, on exactly one operator: the value-producing relational,
  where `FUN_10c1b517` @ `0x10c1b517` runs **two rival expanders in cost-only
  mode and emits the cheaper**.

The reading was frozen against 12 obj cells before its first `cl.exe` and took
**9 of 12** on the graded core. The judgment deliverable comes out **yes**, with
one named blocker and a predicted reach of **0**.

## 1. The tables (deliverable 1) — #2040, #2041

`docs/whitebox/WB_SELECT_FINDINGS.md` §1–§2, §4.

The Rosetta stone PREREG P1.5 asked for is `0x10b1b260`, and finding it first
made every arm readable: `add`=1, `addi`=11, `addze`=21, `cmpi`=46,
`cntlzw`=50, `mulli`=272, `srawi`=327, `subfc`=387, `subfe`=391, `subfic`=395,
`rlandi`=622, `li`=624, `lcarry`=652.

Its attribute word is a small effect model and every bit of it is used
downstream:

| bit | meaning | who reads it |
|---|---|---|
| `0x08` | writes CR0 (is a record form) | `0x10c0718f` |
| **`0x10`** | **has a record form, at opcode + 1** | `0x10c0b300` |
| **`0x20`** | **defines XER[CA]** | `0x10c064cb`, `0x10c0634b` |
| **`0x40`** | **uses XER[CA]** | — (`lcarry` = `0x50`) |

The same byte is exposed as an array at `0x10c3afd8`, indexed by machine opcode.

The in-place expansion switch WB-D §4 saw but never named is
**`FUN_10c182b4` @ `0x10c182b4`** — byte index `0x10c184a8`, **jump table
`0x10c18460`** — and it has only **18 arms**, one of which covers 445 opcodes
and does nothing. PREREG P1.4 predicted it would be a later, different pass
expanding pseudo-ops rather than `+`/`<`, and that this lane would name its
table. Both hit.

## 2. The pattern set (deliverable 2) — #2045, #2046, #2049

The thirteen tables are copy, load-D, load-X, store-D, store-X, negate, add,
sub, mul, div, compare-immediate, compare-register, convert. **The entire
signed/unsigned distinction in the scalar integer set lives in three of them**
— `div` (`divw`/`divwu`), `compare-immediate` (`cmpi`/`cmpli`) and
`compare-register` (`cmp`/`cmpl`). `add`, `sub`, `mul`, the loads and the stores
are constant across signedness.

That is **#1788's answer**, and cells S2 / S12 / `d_if_s` / `d_if_u_call`
confirm it black-box: same source shape, same constant, same `cr6`, `cmpwi`
from `int` and `cmplwi` from `unsigned`.

The per-operator arms are small and they refuted two frozen predictions:

* **`x / 3` is `li 11,3 · divw 3,3,11 · blr`.** `FUN_10c068ee` has exactly one
  constant arm — a positive power of two, which becomes **`srawi` + `addze`**
  (PREREG P4.2, hit, cell S5). **There is no magic-number multiply at `/O1`**
  (P2.4 refuted).
* **`x * 6` is `mulli`.** Power of two → shift; anything else → `mulli`. **No
  shift/add decomposition** (P2.3 refuted).

Record forms are a **fusion at `opcode + 1`** (`FUN_10c0b300`): a compare
against the constant 0, a backwards walk to the defining instruction, and the
attribute bit `0x10`. The CR field falls out of it — `cr0` on the record-form
path, `cr6` otherwise — which is the rule underneath WB-D §7.5's retraction.

## 3. The idiom layer (deliverable 2, flagship) — #2042, #2043

Tuple `0x2ea` → `FUN_10c1b517` @ `0x10c1b517`:

```c
cost_carry  = FUN_10c1ac5c(t, 0);      /* dry run: returns a WORD COUNT */
cost_cntlzw = FUN_10c1af2d(t, 0);
if (cost_cntlzw <= cost_carry) FUN_10c1af2d(t, 1); else FUN_10c1ac5c(t, 1);
```

**The carry expander is unsigned-only.** It normalises every unsigned relation
to `ULE` by swapping operands and **returns 500 = impossible for condition
codes 3–6** (signed LT/LE/GT/GE) — PREREG P3.2, registered cold, hit. For
`x REL K ? A : B` it emits

```
   [ li     t, K       ]      if the bound is a constant
     subfc  t, x, t           (or subfic when the subtrahend is the constant)
                              + an XER[CA] def operand
     lcarry t                 materialise CA as a 0/-1 mask
   [ rlandi t, t, A-B  ]      skipped iff A-B == -1
   [ addi   t, t, B    ]      skipped iff B == 0
```

— so the idiom generalises over arbitrary result constants (P3.3, hit), and
WB-D's unexplained four-word `wbr_cmp_u` sequence is now a *rule*, not a shape.

The two rivals both win in the same obj: `x == 0` takes `cntlzw` (cell S3),
`x != 0` takes the carry route (cell S4).

## 4. The three misses — #2044, #2047

Stated as misses, retracted rather than hedged.

**PREREG P3.4 is REFUTED. There is no value-vs-branch context bit.** Cell S12,
`if (x < 10u) return 1; return 2;`, emitted the identical five-word branchless
carry idiom as the `?:` form — **no branch at all**. The replacement rule, from
eight objs: **a two-way `if` keeps a compare-and-branch iff either arm has a
side effect, or the relation is signed with a non-zero bound.** The context that
matters is the *shape of the arms*, and it is decided by an if-conversion pass
**before** selection whose site this lane did not find.

**`rlandi` is the one unread pass, and it sits under `x & K`.** Cell S11
predicted `rlwinm` for a mask of 8 and got `li 10,8 · and 3,11,10`. Seven
diagnostic cells bound the predicate — masks 2/3/4/8/16 without a bias give
`li`+`and`, masks 4 and 8 *with* a bias give `rlwinm` — and the deciding pass is
`FUN_10c1772b` @ `0x10c1772b`, expansion-switch arm 13. **This lane names it
rather than guessing it**, which is what PREREG P5.4 required.

**Cell S1's setter form.** I predicted `subfic` with an immediate; c2 emitted
`li` + `subc` (= `subfc`), because the `ULT → swap → ULE` normalisation puts the
bound in the minuend position. The reading was right and my instantiation of it
was wrong; scored a MISS because the prediction as written names a word that is
not in the obj.

## 5. The judgment (deliverable 4) — #2048

> **Yes — the port can lower an arbitrary straight-line integer body from a
> derived pattern set, and that set is ≈60 rules. It is gated on ONE unread
> pass, and the class it unlocks converts ZERO TUs on the first scan.**

| what | rules |
|---|---|
| 13 operator tables + 1 signedness bit | ~14 |
| constant-operand tests (`ori`/`or`, `cmpi`/`cmp` with two fit rules, `mulli`, power-of-two mul, power-of-two signed div, AND→`rlandi`) | ~9 |
| record-form fusion + the CR field | 2 |
| narrowing fusions (`lhz`+`extsh` → `lha`; `lbz`+`extsb` stays) | 2 |
| the value-producing relational family (normalisation, two expanders, the tie-break) | ~20 |

First class: **`expr_int_straightline`** — one basic block, integer scalars, no
`&`/`|`/`^` with a constant, no calls, no value-producing relational. Cells
S5–S10 show six shapes of it coming out byte-exact from the reading alone.

**Predicted reach on the 124-TU pool: `0`.** PREREG P5.2 registered exactly this
and it stands, for WB-D §9.3/P5.4's reason — 48 of the frontier's 59 functions
die at the port's IL reader before any emitter question is reachable. What has
changed is the price, not the yield: with WB-D (registers, order), WB-H (loops)
and WB-B (frames), the scalar-integer emitter now has **exactly two named
holes** — `rlandi`'s expansion and the switch decision tree's pivot.

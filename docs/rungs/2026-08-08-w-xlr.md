## 3. #1761 is REFUTED, by an obj and not by an argument (#1781)

**This is the finding to carry off the lane.**

`w-osfinfo` shipped a **rule** for the label-lead surcharge, predicted before its
build and confirmed on its own body:

> **The lead is the number of unconditional intra-section `b` words in the
> body**, because c2 mints a named block label for a `b`'s target and charges the
> counter for it ahead of the function's own `$M` triple.

The brief for this lane said *"your class must satisfy the rule, not pick a
number."* It does not satisfy it.

`CXLrcImpl_CreateClientWithTransport` has **three** unconditional intra-section
`b` words — `+0x4c`, `+0x54`, `+0x78`, all three reaching the same join. The rule
predicts a lead of **3**. The obj forces **2**:

```text
  .gl label counter                       2575
  plan_labels seed  = 2575 + 9            2584
  the /Gy 3-per-function pre-pass         2587
  reference obj:  $M2589 / $M2590 / $T2591
  ⇒ lead = 2589 − 2587 = 2, exactly
```

**Both counterfactuals were built and scanned against real `c2.dll`**, which is
the only grading this project accepts:

| lead | source of the number | verdict |
|---:|---|---|
| 0 | the null control | **`mismatch` (bytes diverge)** |
| **3** | **#1761's own prediction** | **`mismatch` (bytes diverge)** |
| **2** | `LABEL_COUNTER.md` §1.1's surcharge table | **`match`** |

What fits is older and better witnessed: §1.1's **+2 for each distinct
`__savegprlr_N`/`__restgprlr_N` first introduced**, allocated before the
function's own `$M` pair — 29 probes through `scripts/gt_label_stride.py` at both
modes, with an in-TU anchor control on every row. On that table an intra-section
branch costs **nothing at any count**, and this class is the port's first
helper-using frame, so it is the first body that can tell the two apart.

**What this does NOT do is replace the rule.** #1761's four points still charge
1 / 1 / 0 with one-or-zero `b` words each, and there is still no mechanism for
them. A refuted rule plus an honest gap is worth more than a second guess, and
that sentence is written into `IlFunction::label_lead` itself, beside the
paragraph it corrects — because the next reader of that function will read the
file, not this rung.

**The generalization, stated once**: #1761 was a fit to four points, three of
them retrofitted, and its own doc said so. It survived one prediction and died on
the second. **A rule fitted to a population that varies over `{0, 1}` cannot be
told from a constant, and the cell that separates them is the one with three.**

## 4. What the conversion actually needed

### 4.1 `FrameLayout` Class C, and the rule that needed no change (#1783)

```text
  0x00  7d8802a6  mflr r12            three words, whatever `saved_gprs` is —
  0x04  4bfffffd  bl __savegprlr_26   and NO `stw r12,-8(r1)`, because the
  0x08  9421ff70  stwu r1,-144(r1)    helper spills LR itself
  …
  0x90  38210090  addi r1,r1,144      two words, and the function's LAST word
  0x94  4bffff6c  b __restgprlr_26    is a relocation with LK = 0. No `blr`.
```

**The frame SIZE came out of the published rule with nothing special-cased**:
`align16(max(80, 80 + 4) + 8·(1 + 6)) = 144`, which is `CODEGEN_FRAMED_CALLS.md`
§1.2 evaluated at a saved-register count this port had never emitted. That is
worth stating because it is the one place a new frame class could have cost a
new constant and did not.

The pair is gated by **its own** predicate. `out_of_class_ctx` still returns
`frame-savegprlr-helper` and every other emitter still runs it, so the helper
prologue is reachable only from an emitter that asked for it by name; and
`out_of_class_ctx_gpr_helper` refuses a layout that does *not* need the helper,
which is the mirror image. Neither emitter can reach the other's shape.

### 4.2 Two symbols after the `$T` label (#1784)

`docs/CODEGEN_FRAMED_CALLS.md` §2.3a's witnessed group, reproduced exactly:

```text
  .text+aux · fn · $M(end) · CXLrcClient_CreateTransport · ?CreateClient@… ·
  $M(prologue) · .pdata+aux · $T · __restgprlr_26 · __savegprlr_26
```

The pair travels on `coff::Function::helper_externals`. Its **relocations stay in
`calls`** — a REL24 is a REL24 and `text_reloc_plan` reads that list — and
`introduced_externals` **subtracts** the pair rather than skipping it, so the two
lists overlap by name and nothing is emitted twice. Emitting them in the callee
region instead resolves every relocation and moves four symbol indices, which is
`docs/GAPS.md` §6's silent shape.

Their order within the pair is **reverse first-reference**, the same rule the
callee region uses, derived from the two sites rather than written as a literal
pair: the save is the prologue's word and the restore the function's last, so the
restore's symbol is the earlier record.

**The PACKED layout REFUSES the class** (#1787). The body would build fine at
`off`; what has no measured slot is the symbol table, because every witness of
this placement is a `/Gy` obj with a `$T` to put them after. It costs the
workload nothing — the class is `/O1` only and `/O1` implies `/Gy` — and it is
#174's three-cell rung: an honest refusal, not a guessed ordering.

### 4.3 `.sy`'s address-taken bit gets a POSITIVE channel (#1785)

The stack object is what makes this body's frame `locals: 4`, and nothing in the
token stream says a token is four bytes of frame rather than a register. `.sy`
does: flags `0x0021`, decoded and *excluded* since `w-hash`.

`SyBlock::addr_locals` is that fact as a list. It answers *"is this token four
bytes of frame"* where `int_locals`/`ptr_locals` answer *"may this token be
folded into the expression that reads it"* — and the two are true in **disjoint**
cases, which is what makes the widening safe.

**Verdict-neutral by construction, not by measurement**: `read_record` returns a
three-valued `Record` now, the `admissible` predicate that feeds the two older
lists is textually unchanged, and the new arm is reachable only when `admissible`
is false — `flags == 0x0021` is excluded from it by a **field**, not by the order
of two tests. Measured anyway: `int_locals` and `ptr_locals` are empty on all
four rows of the new grid, and the 878-TU per-TU set comparison in §1 is the
whole-corpus check.

It is deliberately narrow: four-byte **integer** scalars only. An address-taken
pointer, array or aggregate is left `Stepped`, because this list's one consumer
turns membership into `FrameLayout::locals` and a kind whose width could differ
is how a `stwu` immediate goes silently wrong.

### 4.4 The hoisted `lis` is the class (#1786)

`0x8007000E` and `0x800710DD` differ only below bit 16, so c2 emits **one**
`lis r26,0x8007` *above* the `cmplwi` that chooses between them, and **one**
`ori` in each arm:

```text
  0x3c  3f408007  lis  r26,0x8007      ← hoisted above the branch
  0x40  2b0b0004  cmplwi cr6,r11,4
  0x44  4098000c  bf   cr6.LT -> 0x50
  0x48  635a000e  ori  r26,r26,0x000e
  0x4c  48000040  b    Ljoin
  0x50  635a10dd  ori  r26,r26,0x10dd
```

Four words. A per-statement lowering writes five, gets every displacement after
the hoist wrong, and **links**. So the reader refuses two constants whose high
halves differ, and refuses any status constant with a zero high half (c2 emits
one `li`) or a zero low half (c2 emits one `lis`). Board **#1706**'s rule a
second time: anything the emitter cannot vary is refused by the reader.

This is `w-osfinfo` §7's tail merge pointing a third way. There one word served
two structurally unrelated statements; here one word serves two arms of a
conditional that the source writes as two independent assignments.

## 6. What is a field, what is pinned, and why

The rule `w-osfinfo` #1767 stated, applied here: **a value is a free field when
varying it changes only an immediate field of the same instruction, and is PINNED
when varying it would change which instruction c2 emits.**

| value | | why |
|---|---|---|
| `k_init` `k_bound` `k_lo` `k_hi` `k_fail` | **5 free fields** | each lands in an `li` / `cmplwi` / `ori` / `lis`+`ori` immediate. Asserted as fields by a test that varies each and checks exactly which word moves |
| **`k_lo` and `k_hi`'s HIGH halves — pinned equal** | refused otherwise | §4.4: they share one hoisted `lis` |
| **every status constant's two halves — pinned non-zero** | refused otherwise | a zero half is a one-word materialization and a shorter body |
| **`result`'s initial value — pinned to 0** | refused otherwise | `li r26,0` is not a field; making it one is a sixth immediate this class has never been graded on |
| **the four formals — pinned at four, each one register** | refused otherwise | they park in r30–r27 by four words the emitter does not vary, and the count decides `saved_gprs` and therefore the helper WIDTH |
| **the callee-saved assignment** | pinned | r31 ← the create result, r30–r27 ← the formals, r26 ← the status. Descending-from-r31 is the shipped rule and it does **not** predict this, because r31 goes to the value defined LAST. Transcribed, and refused when the shape varies |

**Zero words are chosen by a scheduler or a register allocator** — PREREG **D1**,
which did not fire.

## 6. Whitebox — the deliverable under goal (1), which is PRIMARY

Full record: **[`../whitebox/WB_RELATION_FINDINGS.md`](../whitebox/WB_RELATION_FINDINGS.md)**.

Read-before-probe: **no probe grid was run for any claim in it.**

**c2 carries one 5-bit relation code and three contiguous 20-byte tables:**

| VA | transform | shape |
|---|---|---|
| `0x10b189a4` | **signedness** remap, signed → unsigned | idempotent; **EQ and NE are FIXED POINTS** |
| `0x10b189b8` | **strictness** flip, `<` ↔ `<=` | involution |
| `0x10b189cc` | **negation** | involution; **31 xrefs from 26 functions** |

**The relation code is the IL opcode minus `0x1E`** — over-determined by four
independent constraints (§2 of the findings), so it is stated without a probe.

Two board-row consequences:

* **`#1788` is a fixed point, not a coincidence.** *"`int size` and `unsigned
  size` emit the identical `22` byte"* is `a4[1] = 1` and `a4[2] = 2`, and it is
  the same fact for all six relations at once: c2 applies signedness at
  lowering time by table, gated on the operand's `0x2000` type-class nibble
  (`FUN_10c1a908` @ `0x10c1a908`, lookup at `0x10c1a947`).
* **`#423`'s "three-way interaction of (relation, signedness, literal)" is two
  table lookups and a zero test**, in one function: `a4` for signedness, then
  `cc` **once per constant-zero operand** (`0x10c1a96d` for the left,
  `0x10c1a98f` for the right, the second with an operand exchange). The four
  relations that "rewrite at exactly `k = 0`" are exactly the non-fixed-points
  of `cc` in the unsigned block, `(7 10)` and `(8 9)`. **`#423`'s warning is
  strengthened, not retired**: the rewrite is table-driven and unconditional.

`#423` cost a 36-cell probe grid (`work/w-cmp/gt_guard_rel.py`). The read that
replaces it is three `readelf`-grade table dumps and one function. That is
`WHITEBOX_LEVERAGE_2026-08-21.md`'s thesis with a number on it. Board **#3489**.

with an absolute VA, the site that maps an IL relational opcode to c2's internal
relation code"* at p = 0.5. I recovered the **encoding** (`IL − 0x1E`) from the

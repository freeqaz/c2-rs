## 2. The production, read

### 2.1 What `expr-intrinsic-memset` is here

```cpp
struct true_tag {};                                   // an empty tag type
template <class I> inline void aux(I, I, const true_tag&) {}
template <class I, class T> inline void dr(I f, I l, T*) {
    aux(f, l, true_tag());                            // <- THIS BODY
}
```

`true_tag()` is value-initialized into a stack temporary, which c1xx spells as an
**intrinsic `memset`** — selector **173**, `docs/IL_INTRINSIC_CALL.md` §1 — and
the temporary's address is then passed by reference to a callee whose body is
empty. The whole `.ex` body, transcribed from a live capture of
`work/w-inl0/explore/e01.cpp` at the workload's own flags:

```text
  4C 4F 11 53                                the body marker and its scope
  26 <callee-tok>                            the callee symbol push
  BD <ret TYPE> 00 <varint fn-type-id>       the CALL token
    33 86 41 74 80 AD 00 00 00               the intrinsic selector, 173
    40 86 41 74                              the intrinsic-call token, INT result
      33 86 41 74 01 55 86 41 74             the alignment hint  (1)
      33 86 41 74 01 55 86 41 74             the byte count      (1 = sizeof)
      33 86 41 74 00 55 86 41 74             the fill            (0)
      9B <TYPE> <temp-tok> 2C <TYPE> <v>     the destination — a TEMPORARY
      55 <TYPE>
    4C                                       the intrinsic's apply
    9B <TYPE> <temp-tok> 2C <TYPE> <v> 44    THE SAME temporary, by reference
    55 <TYPE>
    ( B9 <formal-tok> <TYPE> 55 <TYPE> )*    the formals, as they are
  4C 4B                                      apply, and discard the result
  <the return plumbing, to the segment end>
```

**The `40`'s result type is a measured discriminator, not an assumption.** On
`src/lazer/game/BustAMovePanel.cpp` the byte run `33 86 41 74 80 AD 00 00 00`
occurs **455** times and the byte after it splits three ways: **446** carry
`40 86 41 74` (this shape), **7** carry `40 86 43 83 08` — a `void *` result,
which is `memset(p, 0, n)` on a real pointer and which c2 lowers to `b <memset>`
**with a REL24** — and **2** are not followed by a `40` at all (an ordinary
literal 173, not a selector).

### 2.2 The count literal is 1, as registered — and #644 still applies

`PREREG.md` §5 registered L1, *"that the count literal is `1`"*, as a prediction
expected to lose. It **held**: `sizeof(true_tag)` is 1 and the capture reads
`01`. It is nonetheless not a gate — the reader decodes align/count/fill as
literals and constrains none of their values, because the soundness comes from
*where* the write lands and not from *how much* of it there is. Constraining a
value that happens to be constant on one corpus is exactly the
"one producer, one contiguous field" mistake #644 records.

### 2.3 Why this is sound, as four things rather than an argument

1. **The walk is TOTAL over the segment.** It begins at the body marker and ends
   by requiring `eat_return_plumbing`'s fail-closed terminal, so every byte of
   the body is consumed by a production above. *"The temporary is read nowhere
   else"* is not a search — there **is** nowhere else. Mutation **M3** removes
   this and a named test goes red.
2. **The answer is CONDITIONAL, and the condition is the callee.** The reader
   returns a **token**, never a verdict; `elide.rs`'s least fixpoint decides.
   Mutation **M2** removes this and 4 of 8 cells go red.
3. **The temporary is the same temporary.** The write's `9B` token and the
   argument's are required to be equal. Mutation **M1** removes this and a named
   test goes red.
4. **Nothing reads a relocation.** Board **#950**'s hazard is inherited verbatim
   and the rule never touches the observable it names.

**Two harness facts that had to be measured before any cell graded anything**,
both recorded because a control that cannot fire is worse than no control:

* **The ANCHOR is PREPENDED here, where `w-empty` appends it.** These cells
  define templates and `w-empty`'s do not. A template instantiation's segment is
  emitted *after* every source-order function, so the **last source-order**
  function carries the module trailer `4F 02 20 00 4F 01 <line>` **without** the
  `4D` that closes it, and `eat_fn_tail` refuses exactly that. Appended, the
  ANCHOR came back `Refused` in **four of eight** cells and every verdict under
  it was worthless.
* **A five-level TAIL PAD is appended.** The `.ex`'s *last* segment ends
  `47 54 01 54 00 4D` with no `4F 02` before it and always refuses as
  `module-end-0x4D`. In a workload TU that is some anonymous instantiation; in a
  five-function cell it was `??$aux@…`, **the empty leaf the whole chain has to
  be seeded from**. A one-level pad was not enough — instantiations are not
  emitted in source order — and five is what the census reads back as
  `empty-body`.

**The 228 are STLport's other overload, and the split is by element type.** The
138 that closed are `_Destroy_Range` over **scalars and pointers** — `PAH`
(`int*`), `PAM` (`float*`), `PAG`, `PAPAV…`; the 232 that did not are over
**class types** — `PAVSymbol` (53), `PAVFace@RndMesh` (10), `PAVColor@Hmx` (7),
`PAVVector3` (6) and 40 more. `__type_traits<T>::has_trivial_destructor` is
`__false_type` for a plain class in this STLport, so those take
`__destroy_range_aux(_first, _last, __false_type)` — a **loop** — and the loop's
return plumbing carries a label, which is `return-scope-close-cflow-label`.

**GRID-M m06 is that shape compiled, and its `/Ob0` row is the finding.** c2
emits one `4e800020` for the wrapper at the workload's flags **and at `/Ob0`**.
So the loop is erased by c2's own dead-code elimination, not by its inliner: the
228 are **mechanism E behind a body the parser cannot read**, board **#922**'s
population one tier up, and the rung that closes them is a **parser** rung. That
is a materially better answer than the one this lane registered.

## 9. Found and not taken

1. **The 228, and the rung is a PARSER rung** (§5). `return-scope-close-cflow-label`
   holds them, m06 compiles the shape, and `/Ob0` says it is E and not I. It is
   the same production `w-seq` §5 already counts at **76** differs on its own
   account, so the two rungs share a dependency and neither may quote the
   other's worth as its own.
2. **The reader fires on 12,690 refused rows and the fixpoint takes 1,409.**
   The dead-temporary idiom is a *general* tag-dispatch shape, not an STLport
   accident — which is also why a name-based special case would have been both
   forbidden and far narrower. The 11,248 that stop are priced by production
   (`fnbyte-noeffect-stop-*`): `return-scope-close-cflow-label` **4,197**,
   `body-0x67` **2,948**, `expr-lit-type-8207` **2,572**,
   `expr-call-in-expr-recv-load-then-type-void-and-op-more` **1,455**,
   `param-width-undetermined:mid` 73, `module-end-0x4D` 3. **Not one of those
   converts a function by itself** — each only lets a chain close — which is
   `w-seq` §5.1's caution repeating.
3. **`fnbyte-noeffect-ref-absent` is 1,046 of the 1,409 admitted rows** — c2
   emitted no `.text` COMDAT for them at all. The fixpoint uses them anyway,
   correctly (a callee that reduces to nothing is a callee whether or not it is
   emitted), and the number is published so nobody reads `-ref-blr 363` as the
   admitted population.
4. **The last segment of every bundle refuses as `module-end-0x4D`** and it
   costs a real function per TU. `eat_fn_tail` requires the module trailer
   `4F 02 20 00 · 4F 01 <line> · 4D`; the last segment has only the `4D`. It cost
   this lane a five-level scaffold to work around in cells (§4) and it is
   **3** rows of the stop histogram on the workload — small, but it is a
   one-byte reader repair with a known answer.
5. **Widening `functions()` to ACCEPT this body is worth ~369 more `exact`** —
   the callees themselves, which c2 emits as `blr` and which the port could too.
   **Declined here** on #971 condition 4: `functions()` refuses a TU when any
   function refuses, so accepting this body admits whole TUs to `PortC2::build`
   that have never been emitted, and that is a `mismatch` risk this lane did not
   grid.

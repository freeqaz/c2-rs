## 5. Standing method

* **Worktree setup first.** A harness worktree has **no toolchain and a cold
  cache**. Run `scripts/configure_existing_worktree.sh`, then **verify**
  `c2rs selftest` prints `PASS` and not `SKIP: toolchain absent` — with no
  toolchain the differential silently grades nothing and a mis-emitting change
  looks exactly like a byte-exact one. That script has two known
  "reports success while doing something else" defects (`#3500`/`#3516`).
* **Prereg first**, committed before the image is opened or code is written.
* **Controls watched RED** before any verdict from them is quoted (`#3336`).
* **Do not commit gate transcripts carrying absolute paths** — two of four
  lanes did last wave and `tracked_artifact_audit.sh` class 3 caught both.
  Sanitize (do not delete — they are your evidence), and verify with the
  audit's own regexes rather than the pattern you substituted on.
* **Restoring a mutation control with `cp`/`mv` keeps the older mtime**, so
  cargo does not rebuild and the *mutated* binary runs for your closing check.
  `touch` and verify.
* **`pgrep -f`/`pkill -f` match command lines and are worktree-independent** —
  they match peers' runs. Wait on a PID with `kill -0`; bound every wait.
* **Read the `GATE:` verdict LINE, never the exit code.** `REFUSED` exits 0.
* `scripts/gate.sh` exceeds the 600 s tool cap: `setsid nohup … </dev/null &
  disown` plus a bounded poll.
* **Bind every published count to a recipe.** Counts unbound to one went stale
  in 48 hours here.

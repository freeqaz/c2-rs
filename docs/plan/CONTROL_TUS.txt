# docs/plan/CONTROL_TUS.txt — the NAMED control for the ObjPlan manifest lane
#
# The 26 TUs whose obj the port reproduces BYTE-EXACTLY at the lane's base
# (tree c277d3bb0, workload 3df8fd5412c2, measured 2026-08-20 by
# `c2rs gap --list work/dc3-workload/files.txt --flags-file .../flags.txt
#  --cwd ../dc3-decomp --jobs 16`, log work/manifest/gap-base.log).
#
# WHY A FILE OF NAMES AND NOT A COUNT. A control pinned by COUNT passes in an
# unprovisioned worktree the moment the count matches (rungs/README rule 1): a
# fresh `git worktree add` has no compilers/, every capture SKIPs, and a
# registered RED reads GREEN. A count match with a SET difference is a finding.
#
# THE JOIN KEY IS THE PATH AS `cl` SEES IT — `src/App.cpp`, never
# `src__App.cpp`, never absolute (gap/sets.rs:19-33). Do not canonicalize.
#
# This set is EXPECTED TO MOVE as the port converts TUs. The lane asserts an
# IDENTITY DIFF (entered / left, BY NAME) against this file on every run and
# prints it; a difference is reported before any other number, because it means
# the tree or the workload stamp moved under the lane.
#
# AND A SET OF NAMES IS STILL NOT A CONTROL WITHOUT ITS OWN SIZE. Measured at
# stamp 6f3a818e9893: of these 26 TUs, SIX have an EMPTY observed emit set
# (decomp_pch, GainEffect, HeadsetPlaybackEffect, PeakDetector, mmx_optimized,
# sse_optimized — also the only empty-observed TUs in the whole 870), ELEVEN
# are 1-vs-1, and only NINE compare a set of >= 2 names; 46 emitted names over
# all 26. So "N of 26 exact" and "N comparisons of nothing" print identically
# unless the size prints too, which is why `plan-control-obs-size`,
# `-obs-empty-tus` and `-substantive-tus` exist. The most likely wrong way is
# the EXTRACTOR collapsing to Some(empty): that makes the exact count go UP and
# the size go to zero. See rungs/2026-08-20-objplan.md §2.5.
#
# NOTE ON THE PARAGRAPH ABOVE ABOUT SKIPPING: it states a real mechanism and it
# is NOT a licence to grep a suite log for `SKIP: toolchain absent`. libtest
# swallows a passing test's stdout, so that count reads 0 in exactly the
# unprovisioned worktree it would be there to detect (board #3341). The
# non-vacuous forms are `C2RS_REQUIRE_TOOLCHAIN=1` with `require_toolchain`
# passing BY NAME, and a non-zero `census_gate` duration.
#
